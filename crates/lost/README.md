# iana-lost

Type-safe, allocation-free Rust bindings for IANA `lost` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-lost = "0.1.0"
```

```rust
use iana_lost::lost_location_profiles::LostLocationProfiles;

assert_eq!(LostLocationProfiles::CIVIC.as_str(), "civic");
```

## Metadata

Enable `metadata` to access `lost_location_profiles::REGISTRIES` and the crate's `GROUPS`.
