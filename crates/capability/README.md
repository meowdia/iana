# iana-capability

Type-safe, allocation-free Rust bindings for IANA `capability` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-capability = "0.1.0"
```

```rust
use iana_capability::capability_codes::CapabilityCodes;

assert_eq!(CapabilityCodes::MULTIPROTOCOL_EXTENSIONS_FOR_BGP_4.value(), 1);
```

## Metadata

Enable `metadata` to access `capability_codes::REGISTRIES` and the crate's `GROUPS`.
