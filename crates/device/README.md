# iana-device

Type-safe, allocation-free Rust bindings for IANA `device` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-device = "0.1.0"
```

```rust
use iana_device::device_identification::DevUrnSubtypes;

assert_eq!(DevUrnSubtypes::MAC.as_str(), "mac");
```

## Metadata

Enable `metadata` to access `device_identification::REGISTRIES` and the crate's `GROUPS`.
