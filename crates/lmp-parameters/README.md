# iana-lmp-parameters

Type-safe, allocation-free Rust bindings for IANA `lmp-parameters` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-lmp-parameters = "0.1.0"
```

```rust
use iana_lmp_parameters::lmp::LmpMessageTypeNameSpace;

assert_eq!(LmpMessageTypeNameSpace::CONFIG_MESSAGE.value(), 1);
```

## Metadata

Enable `metadata` to access `lmp::REGISTRIES` and the crate's `GROUPS`.
