# iana-cpim

Type-safe, allocation-free Rust bindings for IANA `cpim` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-cpim = "0.1.0"
```

```rust
use iana_cpim::cpim_headers::CpimHeaders;

assert_eq!(CpimHeaders::FROM.as_str(), "From");
```

## Metadata

Enable `metadata` to access `cpim_headers::REGISTRIES` and the crate's `GROUPS`.
