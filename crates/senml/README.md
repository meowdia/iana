# iana-senml

Type-safe, allocation-free Rust bindings for IANA `senml` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-senml = "0.1.0"
```

```rust
use iana_senml::senml::SenmlUnits;

assert_eq!(SenmlUnits::M.as_str(), "m");
```

## Metadata

Enable `metadata` to access `senml::REGISTRIES` and the crate's `GROUPS`.
