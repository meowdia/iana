# iana-sig-alg-numbers

Type-safe, allocation-free Rust bindings for IANA `sig-alg-numbers` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-sig-alg-numbers = "0.1.0"
```

```rust
use iana_sig_alg_numbers::sig_alg_numbers::Sig0AlgorithmNumbers;

assert_eq!(Sig0AlgorithmNumbers::RSA_MD5.value(), 1);
```

Enable `metadata` to access `sig_alg_numbers::REGISTRIES` and the crate's `GROUPS`.
