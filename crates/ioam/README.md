# iana-ioam

Type-safe, allocation-free Rust bindings for IANA `ioam` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-ioam = { version = "0.1.0", features = ["ioam"] }
```

```rust
use iana_ioam::ioam::IoamOptionType;

assert_eq!(IoamOptionType::SEE_SECTION_4_4_1.value(), 0);
```

## Features

No catalogs are enabled by default. Add `metadata` alongside catalog features
to access their `REGISTRIES` and the crate's `GROUPS`.

| Feature | Module |
|---|---|
| [`ioam`](https://www.iana.org/assignments/ioam/) | `ioam` |
| [`ioam-capabilities`](https://www.iana.org/assignments/ioam-capabilities/) | `ioam_capabilities` |
