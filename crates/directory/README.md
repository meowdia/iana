# iana-directory

Type-safe, allocation-free Rust bindings for IANA `directory` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-directory = "0.1.0"
```

```rust
use iana_directory::directory_system_names;

assert_eq!(directory_system_names::ID, "directory-system-names");
```

## Metadata

Enable `metadata` to access `directory_system_names::REGISTRIES` and the crate's `GROUPS`.
