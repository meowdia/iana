# iana-coswid

Type-safe, allocation-free Rust bindings for IANA `coswid` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-coswid = "0.1.0"
```

```rust
use iana_coswid::coswid::CoswidItems;

assert_eq!(CoswidItems::TAG_ID.value(), 0);
```

## Metadata

Enable `metadata` to access `coswid::REGISTRIES` and the crate's `GROUPS`.
