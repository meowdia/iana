# iana-lct-header-extensions

Type-safe, allocation-free Rust bindings for IANA `lct-header-extensions` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-lct-header-extensions = "0.1.0"
```

```rust
use iana_lct_header_extensions::lct_header_extensions::LctHeaderExtensionTypes;

assert_eq!(LctHeaderExtensionTypes::EXT_NOP.value(), 0);
```
