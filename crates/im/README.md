# iana-im

Type-safe, allocation-free Rust bindings for IANA `im` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-im = "0.1.0"
```

```rust
use iana_im::im_srv_labels;

assert_eq!(im_srv_labels::ID, "im-srv-labels");
```

## Metadata

Enable `metadata` to access `im_srv_labels::REGISTRIES` and the crate's `GROUPS`.
