# iana-ancp

Type-safe, allocation-free Rust bindings for IANA `ancp` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-ancp = "0.1.0"
```

```rust
use iana_ancp::ancp::AncpMessageTypes;

assert_eq!(AncpMessageTypes::ADJACENCY_PROTOCOL.value(), 10);
```

## Metadata

Enable `metadata` to access `ancp::REGISTRIES` and the crate's `GROUPS`.
