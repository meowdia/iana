# iana-imap

Type-safe, allocation-free Rust bindings for IANA `imap` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-imap = { version = "0.1.0", features = ["imap-annotate-extension"] }
```

```rust
use iana_imap::imap_annotate_extension::ImapAnnotateExtensionEntries;

assert_eq!(ImapAnnotateExtensionEntries::COMMENT.as_str(), "/comment");
```
