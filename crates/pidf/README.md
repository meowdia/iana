# iana-pidf

Type-safe, allocation-free Rust bindings for IANA `pidf` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-pidf = "0.1.0"
```

```rust
use iana_pidf::pidf_lo_civic_address_considerations;

assert_eq!(pidf_lo_civic_address_considerations::ID, "pidf-lo-civic-address-considerations");
```

## Metadata

Enable `metadata` to access `pidf_lo_civic_address_considerations::REGISTRIES` and the crate's `GROUPS`.
