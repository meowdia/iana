# iana-geopriv

Type-safe, allocation-free Rust bindings for IANA `geopriv` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-geopriv = "0.1.0"
```

```rust
use iana_geopriv::geopriv_identifiers::GeoprivIdentifiers;

assert_eq!(GeoprivIdentifiers::URN_IETF_PARAMS_GEOPRIV_RELATIVE_2D.as_str(), "urn:ietf:params:geopriv:relative:2d");
```

## Metadata

Enable `metadata` to access `geopriv_identifiers::REGISTRIES` and the crate's `GROUPS`.
