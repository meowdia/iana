# iana-enum-services

Type-safe, allocation-free Rust bindings for IANA `enum-services` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-enum-services = "0.1.0"
```

```rust
use iana_enum_services::enum_services;

assert_eq!(enum_services::ID, "enum-services");
```
