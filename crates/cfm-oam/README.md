# iana-cfm-oam

Type-safe, allocation-free Rust bindings for IANA `cfm-oam` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-cfm-oam = "0.1.0"
```

```rust
use iana_cfm_oam::cfm_oam::CfmOamIetfOpcodes;

assert_eq!(CfmOamIetfOpcodes::PATH_TRACE_REPLY.value(), 64);
```

## Metadata
