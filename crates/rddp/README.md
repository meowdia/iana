# iana-rddp

Type-safe, allocation-free Rust bindings for IANA `rddp` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-rddp = "0.1.0"
```

```rust
use iana_rddp::rddp;

assert_eq!(rddp::ID, "rddp");
```

## Metadata

Enable `metadata` to access `rddp::REGISTRIES` and the crate's `GROUPS`.
