# iana-gssapi-service-names

Type-safe, allocation-free Rust bindings for IANA `gssapi-service-names` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-gssapi-service-names = "0.1.0"
```

```rust
use iana_gssapi_service_names::gssapi_service_names::GssapiKerberosSaslServiceNames;

assert_eq!(GssapiKerberosSaslServiceNames::RCMD.as_str(), "rcmd");
```

## Metadata

Enable `metadata` to access `gssapi_service_names::REGISTRIES` and the crate's `GROUPS`.
