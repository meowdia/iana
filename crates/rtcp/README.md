# iana-rtcp

Type-safe, allocation-free Rust bindings for IANA `rtcp` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-rtcp = { version = "0.1.0", features = ["rtcp-xr-block-types"] }
```

```rust
use iana_rtcp::rtcp_xr_block_types::RtcpXrBlockType;

assert_eq!(RtcpXrBlockType::LOSS_RLE_REPORT_BLOCK.value(), 1);
```

## Features

No catalogs are enabled by default. Add `metadata` alongside catalog features
