# iana-dlep-parameters

Type-safe, allocation-free Rust bindings for IANA `dlep-parameters` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-dlep-parameters = "0.1.0"
```

```rust
use iana_dlep_parameters::dlep::SignalTypeValues;

assert_eq!(SignalTypeValues::PEER_DISCOVERY_SIGNAL.value(), 1);
```

Enable `metadata` to access `dlep::REGISTRIES` and the crate's `GROUPS`.
