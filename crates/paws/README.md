# iana-paws

Type-safe, allocation-free Rust bindings for IANA `paws` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-paws = "0.1.0"
```

```rust
use iana_paws::paws::PawsRulesetIdRegistry;

assert_eq!(PawsRulesetIdRegistry::FCCTVBANDWHITESPACE_2010.as_str(), "FccTvBandWhiteSpace-2010");
```

## Metadata

Enable `metadata` to access `paws::REGISTRIES` and the crate's `GROUPS`.
