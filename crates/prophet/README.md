# iana-prophet

Type-safe, allocation-free Rust bindings for IANA `prophet` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-prophet = "0.1.0"
```

```rust
use iana_prophet::prophet::DtnRoutingProtocolNumber;

assert_eq!(DtnRoutingProtocolNumber::PROPHET_PROTOCOL.value(), 0);
```

## Metadata

Enable `metadata` to access `prophet::REGISTRIES` and the crate's `GROUPS`.
