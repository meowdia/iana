# iana-bgp

Type-safe, allocation-free Rust bindings for IANA `bgp` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-bgp = { version = "0.1.0", features = ["bgp-parameters"] }
```

```rust
use iana_bgp::bgp::BgpMessageTypes;

assert_eq!(BgpMessageTypes::OPEN.value(), 1);
```

## Features

to access their `REGISTRIES` and the crate's `GROUPS`.
