# iana-srtp

Type-safe, allocation-free Rust bindings for IANA `srtp` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-srtp = "0.1.0"
```

```rust
use iana_srtp::srtp_protection::DtlsSrtpProtectionProfiles;

assert_eq!(DtlsSrtpProtectionProfiles::V0X00_0X01.as_str(), "{0x00, 0x01}");
```

## Metadata

Enable `metadata` to access `srtp_protection::REGISTRIES` and the crate's `GROUPS`.
