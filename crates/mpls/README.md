# iana-mpls

Type-safe, allocation-free Rust bindings for IANA `mpls` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-mpls = { version = "0.1.0", features = ["mpls-id-type"] }
```

```rust
use iana_mpls::mpls_id_type::InformationFieldAndProtocolIdentifierInTheQ2941GenericIdentifier;

assert_eq!(InformationFieldAndProtocolIdentifierInTheQ2941GenericIdentifier::SESSION.value(), 1);
```
