# iana-oncrpc-ids

Type-safe, allocation-free Rust bindings for IANA `oncrpc-ids` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-oncrpc-ids = "0.1.0"
```

```rust
use iana_oncrpc_ids::oncrpc_ids::NetworkIdentifierRNetid;

assert_eq!(NetworkIdentifierRNetid::TCP.as_str(), "\"tcp\"");
```

## Metadata

Enable `metadata` to access `oncrpc_ids::REGISTRIES` and the crate's `GROUPS`.
