# iana-security

Type-safe, allocation-free Rust bindings for IANA `security` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-security = { version = "0.1.0", features = ["security-label-format-selection"] }
```

```rust
use iana_security::security_label_format_selection::SecurityLabelFormatSelectionRegistry;

assert_eq!(SecurityLabelFormatSelectionRegistry::CIPSO_TAG_TYPE_1.value(), 256);
```

## Features

No catalogs are enabled by default. Add `metadata` alongside catalog features
to access their `REGISTRIES` and the crate's `GROUPS`.

| Feature | Module |
