# iana-rpc

Type-safe, allocation-free Rust bindings for IANA `rpc` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-rpc = { version = "0.1.0", features = ["rpc-authentication-numbers"] }
```

```rust
use iana_rpc::rpc_authentication_numbers::RpcAuthenticationFlavorNumbers;

assert_eq!(RpcAuthenticationFlavorNumbers::NO_AUTHENTICATION_SEE_RFC_1831_A_K_A_AUTH_NULL.value(), 0);
```

## Features

No catalogs are enabled by default. Add `metadata` alongside catalog features
to access their `REGISTRIES` and the crate's `GROUPS`.

| Feature | Module |
|---|---|
| [`rpc-authentication-numbers`](https://www.iana.org/assignments/rpc-authentication-numbers/) | `rpc_authentication_numbers` |
| [`rpc-netids`](https://www.iana.org/assignments/rpc-netids/) | `rpc_netids` |
| [`rpc-program-numbers`](https://www.iana.org/assignments/rpc-program-numbers/) | `rpc_program_numbers` |
