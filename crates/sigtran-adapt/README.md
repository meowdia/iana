# iana-sigtran-adapt

Type-safe, allocation-free Rust bindings for IANA `sigtran-adapt` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-sigtran-adapt = "0.1.0"
```

```rust
use iana_sigtran_adapt::sigtran_adapt::MessageClasses;

assert_eq!(MessageClasses::MANAGEMENT_MGMT_MESSAGE.value(), 0);
```
