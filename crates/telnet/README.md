# iana-telnet

Type-safe, allocation-free Rust bindings for IANA `telnet` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-telnet = "0.1.0"
```

```rust
use iana_telnet::telnet_options::TelnetOptions;

assert_eq!(TelnetOptions::BINARY_TRANSMISSION.value(), 0);
```

## Metadata

Enable `metadata` to access `telnet_options::REGISTRIES` and the crate's `GROUPS`.
