# iana-pcim-oids

Type-safe, allocation-free Rust bindings for IANA `pcim-oids` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-pcim-oids = "0.1.0"
```

```rust
use iana_pcim_oids::pcim_oids::PcimschemaLdapDescriptors;

assert_eq!(PcimschemaLdapDescriptors::V6_1_1.as_str(), "6.1.1");
```

## Metadata

Enable `metadata` to access `pcim_oids::REGISTRIES` and the crate's `GROUPS`.
