# iana-msrp

Type-safe, allocation-free Rust bindings for IANA `msrp` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-msrp = "0.1.0"
```

```rust
use iana_msrp::msrp::StatusCodes;

assert_eq!(StatusCodes::SUCCESS.value(), 200);
```

## Metadata

Enable `metadata` to access `msrp::REGISTRIES` and the crate's `GROUPS`.
