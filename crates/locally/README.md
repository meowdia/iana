# iana-locally

Type-safe, allocation-free Rust bindings for IANA `locally` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-locally = "0.1.0"
```

```rust
use iana_locally::locally_served_dns_zones::Ipv4LocallyServedDnsZoneRegistry;

assert_eq!(Ipv4LocallyServedDnsZoneRegistry::V10_IN_ADDR_ARPA.as_str(), "10.IN-ADDR.ARPA");
```

## Metadata

Enable `metadata` to access `locally_served_dns_zones::REGISTRIES` and the crate's `GROUPS`.
