# iana-vot

Type-safe, allocation-free Rust bindings for IANA `vot` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-vot = "0.1.0"
```

```rust
use iana_vot::vot::VectorsOfTrustComponents;

assert_eq!(VectorsOfTrustComponents::P.as_str(), "P");
```

## Metadata

Enable `metadata` to access `vot::REGISTRIES` and the crate's `GROUPS`.
