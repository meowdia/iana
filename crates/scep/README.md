# iana-scep

Type-safe, allocation-free Rust bindings for IANA `scep` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-scep = "0.1.0"
```

```rust
use iana_scep::scep::ScepMessageTypes;

assert_eq!(ScepMessageTypes::VALUE.value(), 0);
```

## Metadata

Enable `metadata` to access `scep::REGISTRIES` and the crate's `GROUPS`.
