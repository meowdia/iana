# iana-tzdist

Type-safe, allocation-free Rust bindings for IANA `tzdist` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-tzdist = { version = "0.1.0", features = ["tzdist-actions"] }
```

```rust
use iana_tzdist::tzdist_actions::TzdistServiceActions;

assert_eq!(TzdistServiceActions::CAPABILITIES.as_str(), "capabilities");
```

## Features

No catalogs are enabled by default. Add `metadata` alongside catalog features
to access their `REGISTRIES` and the crate's `GROUPS`.

| Feature | Module |
|---|---|
| [`tzdist-actions`](https://www.iana.org/assignments/tzdist-actions/) | `tzdist_actions` |
| [`tzdist-identifiers`](https://www.iana.org/assignments/tzdist-identifiers/) | `tzdist_identifiers` |
