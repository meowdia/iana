# iana-xmlers

Type-safe, allocation-free Rust bindings for IANA `xmlers` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-xmlers = "0.1.0"
```

```rust
use iana_xmlers::xmlers::TimeStampTokenType;

assert_eq!(TimeStampTokenType::RFC3161.as_str(), "RFC3161");
```

## Metadata

Enable `metadata` to access `xmlers::REGISTRIES` and the crate's `GROUPS`.
