# iana-mtqp-options

Type-safe, allocation-free Rust bindings for IANA `mtqp-options` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-mtqp-options = "0.1.0"
```

```rust
use iana_mtqp_options::mtqp_options::MtqpOptions;

assert_eq!(MtqpOptions::STARTTLS.as_str(), "STARTTLS");
```

## Metadata

Enable `metadata` to access `mtqp_options::REGISTRIES` and the crate's `GROUPS`.
