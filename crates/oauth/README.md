# iana-oauth

Type-safe, allocation-free Rust bindings for IANA `oauth` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-oauth = "0.1.0"
```

```rust
use iana_oauth::oauth::OauthAccessTokenTypes;

assert_eq!(OauthAccessTokenTypes::BEARER.as_str(), "Bearer");
```

## Metadata

Enable `metadata` to access `oauth::REGISTRIES` and the crate's `GROUPS`.
