# iana-link

Type-safe, allocation-free Rust bindings for IANA `link` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-link = "0.1.0"
```

```rust
use iana_link::link_relations::LinkRelationTypes;

assert_eq!(LinkRelationTypes::ABOUT.as_str(), "about");
```

## Metadata

Enable `metadata` to access `link_relations::REGISTRIES` and the crate's `GROUPS`.
