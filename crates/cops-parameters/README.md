# iana-cops-parameters

Type-safe, allocation-free Rust bindings for IANA `cops-parameters` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-cops-parameters = "0.1.0"
```

```rust
use iana_cops_parameters::cops::ClientTypesValues;

assert_eq!(ClientTypesValues::V0X0.value(), 0);
```

## Metadata

Enable `metadata` to access `cops::REGISTRIES` and the crate's `GROUPS`.
