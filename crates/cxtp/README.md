# iana-cxtp

Type-safe, allocation-free Rust bindings for IANA `cxtp` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-cxtp = "0.1.0"
```

```rust
use iana_cxtp::cxtp::ContextTransferProfileTypeRegistry;

assert_eq!(ContextTransferProfileTypeRegistry::V0X00.value(), 0);
```

## Metadata

Enable `metadata` to access `cxtp::REGISTRIES` and the crate's `GROUPS`.
