# iana-rpl

Type-safe, allocation-free Rust bindings for IANA `rpl` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-rpl = { version = "0.1.0", features = ["rpl"] }
```

```rust
use iana_rpl::rpl::RplControlCodes;

assert_eq!(RplControlCodes::DODAG_INFORMATION_SOLICITATION.value(), 0);
```

## Features

No catalogs are enabled by default. Add `metadata` alongside catalog features
to access their `REGISTRIES` and the crate's `GROUPS`.

| Feature | Module |
|---|---|
| [`rpl`](https://www.iana.org/assignments/rpl/) | `rpl` |
| [`rpl-routing-metric-constraint`](https://www.iana.org/assignments/rpl-routing-metric-constraint/) | `rpl_routing_metric_constraint` |
