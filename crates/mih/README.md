# iana-mih

Type-safe, allocation-free Rust bindings for IANA `mih` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-mih = "0.1.0"
```

```rust
use iana_mih::mih;

assert_eq!(mih::ID, "mih");
```

## Metadata

Enable `metadata` to access `mih::REGISTRIES` and the crate's `GROUPS`.
