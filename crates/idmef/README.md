# iana-idmef

Type-safe, allocation-free Rust bindings for IANA `idmef` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-idmef = "0.1.0"
```

```rust
use iana_idmef::idmef;

assert_eq!(idmef::ID, "idmef-parameters");
```

## Metadata

Enable `metadata` to access `idmef::REGISTRIES` and the crate's `GROUPS`.
