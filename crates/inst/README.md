# iana-inst

Type-safe, allocation-free Rust bindings for IANA `inst` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-inst = "0.1.0"
```

```rust
use iana_inst::inst_man_values::InstanceManipulationValues;

assert_eq!(InstanceManipulationValues::VCDIFF.as_str(), "vcdiff");
```

## Metadata

Enable `metadata` to access `inst_man_values::REGISTRIES` and the crate's `GROUPS`.
