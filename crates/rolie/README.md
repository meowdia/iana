# iana-rolie

Type-safe, allocation-free Rust bindings for IANA `rolie` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-rolie = "0.1.0"
```

```rust
use iana_rolie::rolie::RolieUrnParameters;

assert_eq!(RolieUrnParameters::CATEGORY_INFORMATION_TYPE.as_str(), "category:information-type");
```

## Metadata

Enable `metadata` to access `rolie::REGISTRIES` and the crate's `GROUPS`.
