# iana-tunnel

Type-safe, allocation-free Rust bindings for IANA `tunnel` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-tunnel = "0.1.0"
```

```rust
use iana_tunnel::tunnel_setup_protocol;

assert_eq!(tunnel_setup_protocol::ID, "tunnel-setup-protocol");
```
