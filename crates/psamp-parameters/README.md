# iana-psamp-parameters

Type-safe, allocation-free Rust bindings for IANA `psamp-parameters` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-psamp-parameters = "0.1.0"
```

```rust
use iana_psamp_parameters::psamp;

assert_eq!(psamp::ID, "psamp-parameters");
```

## Metadata

Enable `metadata` to access `psamp::REGISTRIES` and the crate's `GROUPS`.
