# iana-ikev2

Type-safe, allocation-free Rust bindings for IANA `ikev2` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-ikev2 = "0.1.0"
```

```rust
use iana_ikev2::ikev2::Ikev2ExchangeTypes;

assert_eq!(Ikev2ExchangeTypes::IKE_SA_INIT.value(), 34);
```

## Metadata

Enable `metadata` to access `ikev2::REGISTRIES` and the crate's `GROUPS`.
