# iana-webauthn

Type-safe, allocation-free Rust bindings for IANA `webauthn` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-webauthn = "0.1.0"
```

```rust
use iana_webauthn::webauthn::WebauthnAttestationStatementFormatIdentifiers;

assert_eq!(WebauthnAttestationStatementFormatIdentifiers::PACKED.as_str(), "packed");
```

## Metadata

Enable `metadata` to access `webauthn::REGISTRIES` and the crate's `GROUPS`.
