# iana-jscalendar

Type-safe, allocation-free Rust bindings for IANA `jscalendar` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-jscalendar = "0.1.0"
```

```rust
use iana_jscalendar::jscalendar::JscalendarProperties;

assert_eq!(JscalendarProperties::STRING.as_str(), "String");
```

## Metadata

Enable `metadata` to access `jscalendar::REGISTRIES` and the crate's `GROUPS`.
