# iana-address

Type-safe, allocation-free Rust bindings for IANA `address` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-address = "0.1.0"
```

```rust
use iana_address::address_family_numbers::AddressFamilyNumbers;

assert_eq!(AddressFamilyNumbers::IP_IP_VERSION_4.value(), 1);
```

## Metadata

Enable `metadata` to access `address_family_numbers::REGISTRIES` and the crate's `GROUPS`.
