# iana-ds

Type-safe, allocation-free Rust bindings for IANA `ds` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-ds = "0.1.0"
```

```rust
use iana_ds::ds_rr_types::DigestAlgorithms;

assert_eq!(DigestAlgorithms::SHA_1.value(), 1);
```

## Metadata

Enable `metadata` to access `ds_rr_types::REGISTRIES` and the crate's `GROUPS`.
