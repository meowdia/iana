# iana-gist

Type-safe, allocation-free Rust bindings for IANA `gist` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-gist = "0.1.0"
```

```rust
use iana_gist::gist::NsisSignalingLayerProtocolNslpIdentifiers;

assert_eq!(NsisSignalingLayerProtocolNslpIdentifiers::USED_FOR_GIST_MESSAGES_NOT_RELATED_TO_ANY_SIGNALLING_APPLICATION.value(), 0);
```
