# iana-epp

Type-safe, allocation-free Rust bindings for IANA `epp` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-epp = { version = "0.1.0", features = ["epp-extension-role-values"] }
```

```rust
use iana_epp::epp_extension_role_values::EppOrganizationRoleValues;

assert_eq!(EppOrganizationRoleValues::REGISTRAR.as_str(), "registrar");
```

## Features

No catalogs are enabled by default. Add `metadata` alongside catalog features
to access their `REGISTRIES` and the crate's `GROUPS`.
