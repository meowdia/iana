# iana-ipv6

Type-safe, allocation-free Rust bindings for IANA `ipv6` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-ipv6 = { version = "0.1.0", features = ["ipv6-parameters"] }
```

```rust
use iana_ipv6::ipv6::Ipv6ExtensionHeaderTypes;

assert_eq!(Ipv6ExtensionHeaderTypes::IPV6_HOP_BY_HOP_OPTION.value(), 0);
```
