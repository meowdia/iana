# iana-hip

Type-safe, allocation-free Rust bindings for IANA `hip` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-hip = "0.1.0"
```

```rust
use iana_hip::hip::PacketTypes;

assert_eq!(PacketTypes::I1_THE_HIP_INITIATOR_PACKET.value(), 1);
```
