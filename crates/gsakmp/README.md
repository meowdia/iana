# iana-gsakmp

Type-safe, allocation-free Rust bindings for IANA `gsakmp` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-gsakmp = "0.1.0"
```

```rust
use iana_gsakmp::gsakmp::GsakmpGroupIdentificationTypes;

assert_eq!(GsakmpGroupIdentificationTypes::FORMAT_DEFINED_IN_SECTION_7_1_1_1_1_OF.value(), 1);
```

## Metadata

Enable `metadata` to access `gsakmp::REGISTRIES` and the crate's `GROUPS`.
