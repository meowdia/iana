# iana-syslog

Type-safe, allocation-free Rust bindings for IANA `syslog` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-syslog = "0.1.0"
```

```rust
use iana_syslog::syslog::SyslogMessageFacilities;

assert_eq!(SyslogMessageFacilities::KERNEL_MESSAGES.value(), 0);
```

## Metadata

Enable `metadata` to access `syslog::REGISTRIES` and the crate's `GROUPS`.
