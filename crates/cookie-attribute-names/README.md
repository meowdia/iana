# iana-cookie-attribute-names

Type-safe, allocation-free Rust bindings for IANA `cookie-attribute-names` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-cookie-attribute-names = "0.1.0"
```

```rust
use iana_cookie_attribute_names::cookie_attribute_names::CookieAttributes;

assert_eq!(CookieAttributes::DOMAIN.as_str(), "Domain");
```

## Metadata

Enable `metadata` to access `cookie_attribute_names::REGISTRIES` and the crate's `GROUPS`.
