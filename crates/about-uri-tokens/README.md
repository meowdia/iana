# iana-about-uri-tokens

Type-safe, allocation-free Rust bindings for IANA `about-uri-tokens` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-about-uri-tokens = "0.1.0"
```

```rust
use iana_about_uri_tokens::about_uri_tokens::AboutUriTokens;

assert_eq!(AboutUriTokens::BLANK.as_str(), "blank");
```

## Metadata

Enable `metadata` to access `about_uri_tokens::REGISTRIES` and the crate's `GROUPS`.
