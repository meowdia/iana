# iana-rserpool

Type-safe, allocation-free Rust bindings for IANA `rserpool` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-rserpool = "0.1.0"
```

```rust
use iana_rserpool::rserpool::AggregateServerAccessProtocolAsapMessageTypes;

assert_eq!(AggregateServerAccessProtocolAsapMessageTypes::ASAP_REGISTRATION.value(), 1);
```

## Metadata

Enable `metadata` to access `rserpool::REGISTRIES` and the crate's `GROUPS`.
