# iana-special

Type-safe, allocation-free Rust bindings for IANA `special` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-special = { version = "0.1.0", features = ["special-registry"] }
```

```rust
use iana_special::special_registry::SpecialPeopleNumbersRegistry;

assert_eq!(SpecialPeopleNumbersRegistry::JON_POSTEL.value(), 1);
```

## Features

No catalogs are enabled by default. Add `metadata` alongside catalog features
to access their `REGISTRIES` and the crate's `GROUPS`.

| Feature | Module |
|---|---|
| [`special-registry`](https://www.iana.org/assignments/special-registry/) | `special_registry` |
| [`special-use-domain-names`](https://www.iana.org/assignments/special-use-domain-names/) | `special_use_domain_names` |
