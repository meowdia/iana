# iana-msrp-parameters

Type-safe, allocation-free Rust bindings for IANA `msrp-parameters` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-msrp-parameters = "0.1.0"
```

```rust
use iana_msrp_parameters::msrp::StatusCodes;

assert_eq!(StatusCodes::SUCCESS.value(), 200);
```

## Metadata

Enable `metadata` to access `msrp::REGISTRIES` and the crate's `GROUPS`.
