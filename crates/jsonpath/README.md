# iana-jsonpath

Type-safe, allocation-free Rust bindings for IANA `jsonpath` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-jsonpath = "0.1.0"
```

```rust
use iana_jsonpath::jsonpath::FunctionExtensions;

assert_eq!(FunctionExtensions::LENGTH.as_str(), "length");
```

## Metadata

Enable `metadata` to access `jsonpath::REGISTRIES` and the crate's `GROUPS`.
