# iana-pt

Type-safe, allocation-free Rust bindings for IANA `pt` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-pt = { version = "0.1.0", features = ["pt-eap"] }
```

```rust
use iana_pt::pt_eap::PtEapVersions;

assert_eq!(PtEapVersions::V0.value(), 0);
```

## Features

No catalogs are enabled by default. Add `metadata` alongside catalog features
to access their `REGISTRIES` and the crate's `GROUPS`.

| Feature | Module |
|---|---|
| [`pt-eap`](https://www.iana.org/assignments/pt-eap/) | `pt_eap` |
| [`pt-tls-parameters`](https://www.iana.org/assignments/pt-tls-parameters/) | `pt_tls` |
