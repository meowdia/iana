# iana-sieve

Type-safe, allocation-free Rust bindings for IANA `sieve` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-sieve = { version = "0.1.0", features = ["sieve-environment-items"] }
```

```rust
use iana_sieve::sieve_environment_items::SieveEnvironmentItems;

assert_eq!(SieveEnvironmentItems::DOMAIN.as_str(), "domain");
```

## Features

No catalogs are enabled by default. Add `metadata` alongside catalog features
to access their `REGISTRIES` and the crate's `GROUPS`.

| Feature | Module |
