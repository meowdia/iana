# iana-mib

Type-safe, allocation-free Rust bindings for IANA `mib` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-mib = "0.1.0"
```

```rust
use iana_mib::mib_modules;

assert_eq!(mib_modules::ID, "mib-modules");
```

## Metadata

Enable `metadata` to access `mib_modules::REGISTRIES` and the crate's `GROUPS`.
