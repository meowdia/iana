# iana-cmp

Type-safe, allocation-free Rust bindings for IANA `cmp` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-cmp = "0.1.0"
```

```rust
use iana_cmp::cmp::CmpWellKnownUriPathSegments;

assert_eq!(CmpWellKnownUriPathSegments::P.as_str(), "p");
```

## Metadata

Enable `metadata` to access `cmp::REGISTRIES` and the crate's `GROUPS`.
