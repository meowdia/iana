# iana-imdn

Type-safe, allocation-free Rust bindings for IANA `imdn` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-imdn = "0.1.0"
```

```rust
use iana_imdn::imdn::ImdnHeaders;

assert_eq!(ImdnHeaders::DISPOSITION_NOTIFICATION.as_str(), "Disposition-Notification");
```

## Metadata

Enable `metadata` to access `imdn::REGISTRIES` and the crate's `GROUPS`.
