# iana-bier

Type-safe, allocation-free Rust bindings for IANA `bier` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-bier = "0.1.0"
```

```rust
use iana_bier::bier::BierNextProtocolIdentifiers;

assert_eq!(BierNextProtocolIdentifiers::MPLS_PACKET_WITH_DOWNSTREAM_ASSIGNED_LABEL_AT_TOP_OF_STACK.value(), 1);
```

## Metadata

Enable `metadata` to access `bier::REGISTRIES` and the crate's `GROUPS`.
