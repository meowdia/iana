# iana-cont

Type-safe, allocation-free Rust bindings for IANA `cont` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-cont = "0.1.0"
```

```rust
use iana_cont::cont_disp::ContentDispositionValues;

assert_eq!(ContentDispositionValues::INLINE.as_str(), "inline");
```

## Metadata

Enable `metadata` to access `cont_disp::REGISTRIES` and the crate's `GROUPS`.
