# iana-stun-parameters

Type-safe, allocation-free Rust bindings for IANA `stun-parameters` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-stun-parameters = "0.1.0"
```

```rust
use iana_stun_parameters::stun::StunMethods;

assert_eq!(StunMethods::BINDING.value(), 1);
```

## Metadata

Enable `metadata` to access `stun::REGISTRIES` and the crate's `GROUPS`.
