# iana-audio

Type-safe, allocation-free Rust bindings for IANA `audio` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-audio = "0.1.0"
```

```rust
use iana_audio::audio_telephone_event_registry;

assert_eq!(audio_telephone_event_registry::ID, "audio-telephone-event-registry");
```

## Metadata

Enable `metadata` to access `audio_telephone_event_registry::REGISTRIES` and the crate's `GROUPS`.
