# iana-isis

Type-safe, allocation-free Rust bindings for IANA `isis` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-isis = { version = "0.1.0", features = ["isis-mt-parameters"] }
```

```rust
use iana_isis::isis_mt::IsIsMultiTopologyIdValues;

assert_eq!(IsIsMultiTopologyIdValues::EQUIVALENT_TO_THE_STANDARD_TOPOLOGY.value(), 0);
```

## Features

No catalogs are enabled by default. Add `metadata` alongside catalog features
to access their `REGISTRIES` and the crate's `GROUPS`.
