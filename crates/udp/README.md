# iana-udp

Type-safe, allocation-free Rust bindings for IANA `udp` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-udp = "0.1.0"
```

```rust
use iana_udp::udp::UdpOptionKindNumbers;

assert_eq!(UdpOptionKindNumbers::END_OF_OPTIONS_LIST_EOL.value(), 0);
```

## Metadata

Enable `metadata` to access `udp::REGISTRIES` and the crate's `GROUPS`.
