# iana-netnews

Type-safe, allocation-free Rust bindings for IANA `netnews` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-netnews = "0.1.0"
```

```rust
use iana_netnews::netnews::NetnewsCancelLockHashAlgorithms;

assert_eq!(NetnewsCancelLockHashAlgorithms::MD5.as_str(), "md5");
```

## Metadata

Enable `metadata` to access `netnews::REGISTRIES` and the crate's `GROUPS`.
