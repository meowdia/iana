# iana-as

Type-safe, allocation-free Rust bindings for IANA `as` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-as = "0.1.0"
```

```rust
use iana_as::as_numbers;

assert_eq!(as_numbers::ID, "as-numbers");
```

## Metadata

Enable `metadata` to access `as_numbers::REGISTRIES` and the crate's `GROUPS`.
