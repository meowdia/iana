# iana-ccnx

Type-safe, allocation-free Rust bindings for IANA `ccnx` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-ccnx = "0.1.0"
```

```rust
use iana_ccnx::ccnx::CcnxPacketTypes;

assert_eq!(CcnxPacketTypes::PT_INTEREST.value(), 0);
```

## Metadata

Enable `metadata` to access `ccnx::REGISTRIES` and the crate's `GROUPS`.
