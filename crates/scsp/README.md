# iana-scsp

Type-safe, allocation-free Rust bindings for IANA `scsp` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-scsp = "0.1.0"
```

```rust
use iana_scsp::scsp_numbers::ProtocolIds;

assert_eq!(ProtocolIds::ATMARP.value(), 1);
```

## Metadata

Enable `metadata` to access `scsp_numbers::REGISTRIES` and the crate's `GROUPS`.
