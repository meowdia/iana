# iana-gnap

Type-safe, allocation-free Rust bindings for IANA `gnap` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-gnap = "0.1.0"
```

```rust
use iana_gnap::gnap::GnapGrantRequestParameters;

assert_eq!(GnapGrantRequestParameters::ACCESS_TOKEN.as_str(), "access_token");
```

## Metadata

Enable `metadata` to access `gnap::REGISTRIES` and the crate's `GROUPS`.
