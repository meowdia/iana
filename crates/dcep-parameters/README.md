# iana-dcep-parameters

Type-safe, allocation-free Rust bindings for IANA `dcep-parameters` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-dcep-parameters = "0.1.0"
```

```rust
use iana_dcep_parameters::dcep::MessageTypes;

assert_eq!(MessageTypes::DATA_CHANNEL_ACK.value(), 2);
```

## Metadata

Enable `metadata` to access `dcep::REGISTRIES` and the crate's `GROUPS`.
