# iana-gmpls

Type-safe, allocation-free Rust bindings for IANA `gmpls` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-gmpls = { version = "0.1.0", features = ["gmpls-sig-parameters"] }
```

```rust
use iana_gmpls::gmpls_sig::LspEncodingTypes;

assert_eq!(LspEncodingTypes::V0.value(), 0);
```

## Features

No catalogs are enabled by default. Add `metadata` alongside catalog features
to access their `REGISTRIES` and the crate's `GROUPS`.

| Feature | Module |
|---|---|
| [`gmpls-sig-parameters`](https://www.iana.org/assignments/gmpls-sig-parameters/) | `gmpls_sig` |
| [`gmpls-wson`](https://www.iana.org/assignments/gmpls-wson/) | `gmpls_wson` |
