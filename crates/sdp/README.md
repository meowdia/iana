# iana-sdp

Type-safe, allocation-free Rust bindings for IANA `sdp` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-sdp = { version = "0.1.0", features = ["sdp-parameters"] }
```

```rust
use iana_sdp::sdp::Media;

assert_eq!(Media::AUDIO.as_str(), "audio");
```

## Features

No catalogs are enabled by default. Add `metadata` alongside catalog features
to access their `REGISTRIES` and the crate's `GROUPS`.

| Feature | Module |
|---|---|
| [`sdp-parameters`](https://www.iana.org/assignments/sdp-parameters/) | `sdp` |
| [`sdp-security-descriptions`](https://www.iana.org/assignments/sdp-security-descriptions/) | `sdp_security_descriptions` |
