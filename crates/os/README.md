# iana-os

Type-safe, allocation-free Rust bindings for IANA `os` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-os = "0.1.0"
```

```rust
use iana_os::os_specific::OsSpecificFactNames;

assert_eq!(OsSpecificFactNames::UNIX.as_str(), "Unix");
```

## Metadata

Enable `metadata` to access `os_specific::REGISTRIES` and the crate's `GROUPS`.
