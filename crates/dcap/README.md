# iana-dcap

Type-safe, allocation-free Rust bindings for IANA `dcap` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-dcap = "0.1.0"
```

```rust
use iana_dcap::dcap::DataLinkSwitchingProtocolFrameCodes;

assert_eq!(DataLinkSwitchingProtocolFrameCodes::CAN_U_REACH.as_str(), "CAN_U_REACH");
```

## Metadata

Enable `metadata` to access `dcap::REGISTRIES` and the crate's `GROUPS`.
