# iana-uaddr

Type-safe, allocation-free Rust bindings for IANA `uaddr` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-uaddr = "0.1.0"
```

```rust
use iana_uaddr::uaddr_formats::OncRpcUaddrFormatRegistry;

assert_eq!(OncRpcUaddrFormatRegistry::SYSTEM_V_RELEASE_4_LOOPBACK_TRANSPORT_UADDR_FORMAT_SECTION_4_2_3_1_OF.value(), 0);
```

## Metadata

Enable `metadata` to access `uaddr_formats::REGISTRIES` and the crate's `GROUPS`.
