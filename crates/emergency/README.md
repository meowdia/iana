# iana-emergency

Type-safe, allocation-free Rust bindings for IANA `emergency` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-emergency = { version = "0.1.0", features = ["emergency-call-additional-data"] }
```

```rust
use iana_emergency::emergency_call_additional_data::ProviderIdSeries;

assert_eq!(ProviderIdSeries::NENA.as_str(), "NENA");
```

## Features

No catalogs are enabled by default. Add `metadata` alongside catalog features
to access their `REGISTRIES` and the crate's `GROUPS`.

| Feature | Module |
|---|---|
| [`emergency-call-additional-data`](https://www.iana.org/assignments/emergency-call-additional-data/) | `emergency_call_additional_data` |
| [`emergency-call-metadata-control-data`](https://www.iana.org/assignments/emergency-call-metadata-control-data/) | `emergency_call_metadata_control_data` |
