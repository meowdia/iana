# iana-dots

Type-safe, allocation-free Rust bindings for IANA `dots` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-dots = "0.1.0"
```

```rust
use iana_dots::dots::DotsSignalChannelCborKeyValues;

assert_eq!(DotsSignalChannelCborKeyValues::IETF_DOTS_SIGNAL_CHANNEL_MITIGATION_SCOPE.as_str(), "ietf-dots-signal-channel:mitigation-scope");
```
