# iana-leighton

Type-safe, allocation-free Rust bindings for IANA `leighton` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-leighton = "0.1.0"
```

```rust
use iana_leighton::leighton_micali_signatures::LeightonMicaliSignaturesLms;

assert_eq!(LeightonMicaliSignaturesLms::LMS_SHA256_M32_H5.value(), 5);
```

## Metadata

Enable `metadata` to access `leighton_micali_signatures::REGISTRIES` and the crate's `GROUPS`.
