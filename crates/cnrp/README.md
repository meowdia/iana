# iana-cnrp

Type-safe, allocation-free Rust bindings for IANA `cnrp` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-cnrp = "0.1.0"
```

```rust
use iana_cnrp::cnrp::Properties;

assert_eq!(Properties::GEOGRAPHY.as_str(), "geography");
```

## Metadata

Enable `metadata` to access `cnrp::REGISTRIES` and the crate's `GROUPS`.
