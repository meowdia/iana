# iana-bfd-parameters

Type-safe, allocation-free Rust bindings for IANA `bfd-parameters` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-bfd-parameters = "0.1.0"
```

```rust
use iana_bfd_parameters::bfd::BfdDiagnosticCodes;

assert_eq!(BfdDiagnosticCodes::V0.value(), 0);
```

## Metadata

Enable `metadata` to access `bfd::REGISTRIES` and the crate's `GROUPS`.
