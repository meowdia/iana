# iana-teap-parameters

Type-safe, allocation-free Rust bindings for IANA `teap-parameters` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-teap-parameters = "0.1.0"
```

```rust
use iana_teap_parameters::teap::TeapTlvTypes;

assert_eq!(TeapTlvTypes::AUTHORITY_ID_TLV.value(), 1);
```

## Metadata

Enable `metadata` to access `teap::REGISTRIES` and the crate's `GROUPS`.
