# iana-ppsp-tp

Type-safe, allocation-free Rust bindings for IANA `ppsp-tp` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-ppsp-tp = "0.1.0"
```

```rust
use iana_ppsp_tp::ppsp_tp::PpstpVersionNumberRegistry;

assert_eq!(PpstpVersionNumberRegistry::PPSTP_VERSION_1.value(), 1);
```

## Metadata

Enable `metadata` to access `ppsp_tp::REGISTRIES` and the crate's `GROUPS`.
