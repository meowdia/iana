# iana-ecml

Type-safe, allocation-free Rust bindings for IANA `ecml` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-ecml = "0.1.0"
```

```rust
use iana_ecml::ecml::UrnPrefixUrnIetfParamsEcml;

assert_eq!(UrnPrefixUrnIetfParamsEcml::V2_0.as_str(), "v2.0");
```

## Metadata

Enable `metadata` to access `ecml::REGISTRIES` and the crate's `GROUPS`.
