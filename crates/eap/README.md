# iana-eap

Type-safe, allocation-free Rust bindings for IANA `eap` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-eap = { version = "0.1.0", features = ["eap-channel-binding-parameters"] }
```

```rust
use iana_eap::eap_channel_binding::EapChannelBindingCodes;

assert_eq!(EapChannelBindingCodes::CHANNEL_BINDING_DATA_FROM_CLIENT.value(), 1);
```
