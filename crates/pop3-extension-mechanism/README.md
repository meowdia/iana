# iana-pop3-extension-mechanism

Type-safe, allocation-free Rust bindings for IANA `pop3-extension-mechanism` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-pop3-extension-mechanism = "0.1.0"
```

```rust
use iana_pop3_extension_mechanism::pop3_extension_mechanism::Pop3Capabilities;

assert_eq!(Pop3Capabilities::TOP.as_str(), "TOP");
```
