# iana-openpgp

Type-safe, allocation-free Rust bindings for IANA `openpgp` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-openpgp = "0.1.0"
```

```rust
use iana_openpgp::openpgp::OpenpgpStringToKeyS2kTypes;

assert_eq!(OpenpgpStringToKeyS2kTypes::SIMPLE_S2K.value(), 0);
```

## Metadata

Enable `metadata` to access `openpgp::REGISTRIES` and the crate's `GROUPS`.
