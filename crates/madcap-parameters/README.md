# iana-madcap-parameters

Type-safe, allocation-free Rust bindings for IANA `madcap-parameters` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-madcap-parameters = "0.1.0"
```

```rust
use iana_madcap_parameters::madcap::MadcapMessageTypes;

assert_eq!(MadcapMessageTypes::DISCOVER.value(), 1);
```

## Metadata

Enable `metadata` to access `madcap::REGISTRIES` and the crate's `GROUPS`.
