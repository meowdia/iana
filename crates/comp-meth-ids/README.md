# iana-comp-meth-ids

Type-safe, allocation-free Rust bindings for IANA `comp-meth-ids` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-comp-meth-ids = "0.1.0"
```

```rust
use iana_comp_meth_ids::comp_meth_ids::TlsCompressionMethodIdentifiers;

assert_eq!(TlsCompressionMethodIdentifiers::NULL.value(), 0);
```
