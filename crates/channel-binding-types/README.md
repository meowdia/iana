# iana-channel-binding-types

Type-safe, allocation-free Rust bindings for IANA `channel-binding-types` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-channel-binding-types = "0.1.0"
```

```rust
use iana_channel_binding_types::channel_binding_types::ChannelBindingTypes;

assert_eq!(ChannelBindingTypes::TLS_SERVER_END_POINT.as_str(), "tls-server-end-point");
```

## Metadata

Enable `metadata` to access `channel_binding_types::REGISTRIES` and the crate's `GROUPS`.
