# iana-dsn-types

Type-safe, allocation-free Rust bindings for IANA `dsn-types` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-dsn-types = "0.1.0"
```

```rust
use iana_dsn_types::dsn_types;

assert_eq!(dsn_types::ID, "dsn-types");
```

## Metadata

Enable `metadata` to access `dsn_types::REGISTRIES` and the crate's `GROUPS`.
