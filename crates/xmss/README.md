# iana-xmss

Type-safe, allocation-free Rust bindings for IANA `xmss` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-xmss = "0.1.0"
```

```rust
use iana_xmss::xmss_extended_hash_based_signatures::WotsSignatures;

assert_eq!(WotsSignatures::WOTSP_SHA2_256.value(), 1);
```

## Metadata

Enable `metadata` to access `xmss_extended_hash_based_signatures::REGISTRIES` and the crate's `GROUPS`.
