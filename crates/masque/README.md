# iana-masque

Type-safe, allocation-free Rust bindings for IANA `masque` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-masque = "0.1.0"
```

```rust
use iana_masque::masque::MasqueUriSuffixes;

assert_eq!(MasqueUriSuffixes::UDP.as_str(), "udp");
```

## Metadata

Enable `metadata` to access `masque::REGISTRIES` and the crate's `GROUPS`.
