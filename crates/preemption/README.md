# iana-preemption

Type-safe, allocation-free Rust bindings for IANA `preemption` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-preemption = "0.1.0"
```

```rust
use iana_preemption::preemption_namespace;

assert_eq!(preemption_namespace::ID, "preemption-namespace");
```

## Metadata

Enable `metadata` to access `preemption_namespace::REGISTRIES` and the crate's `GROUPS`.
