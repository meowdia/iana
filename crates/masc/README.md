# iana-masc

Type-safe, allocation-free Rust bindings for IANA `masc` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-masc = "0.1.0"
```

```rust
use iana_masc::masc::MascMessageTypes;

assert_eq!(MascMessageTypes::OPEN.value(), 1);
```

## Metadata

Enable `metadata` to access `masc::REGISTRIES` and the crate's `GROUPS`.
