# iana-machine-names

Type-safe, allocation-free Rust bindings for IANA `machine-names` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-machine-names = "0.1.0"
```

```rust
use iana_machine_names::machine_names::MachineNames;

assert_eq!(MachineNames::AMIGA_500.as_str(), "AMIGA-500");
```

## Metadata

Enable `metadata` to access `machine_names::REGISTRIES` and the crate's `GROUPS`.
