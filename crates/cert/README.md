# iana-cert

Type-safe, allocation-free Rust bindings for IANA `cert` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-cert = "0.1.0"
```

```rust
use iana_cert::cert_rr_types;

assert_eq!(cert_rr_types::ID, "cert-rr-types");
```

## Metadata

Enable `metadata` to access `cert_rr_types::REGISTRIES` and the crate's `GROUPS`.
