# iana-wave

Type-safe, allocation-free Rust bindings for IANA `wave` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-wave = "0.1.0"
```

```rust
use iana_wave::wave_avi_codec_registry::SectionAAudioCodecsFromTheMicrosoftWaveRegistry;

assert_eq!(SectionAAudioCodecsFromTheMicrosoftWaveRegistry::MICROSOFT_UNKNOWN_WAVE_FORMAT.as_str(), "Microsoft Unknown Wave Format");
```

## Metadata

Enable `metadata` to access `wave_avi_codec_registry::REGISTRIES` and the crate's `GROUPS`.
