# iana-ppp

Type-safe, allocation-free Rust bindings for IANA `ppp` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-ppp = "0.1.0"
```

```rust
use iana_ppp::ppp_numbers::PppLinkControlProtocolLcpAndInternetProtocolControlProtocolIpcpCodes;

assert_eq!(PppLinkControlProtocolLcpAndInternetProtocolControlProtocolIpcpCodes::VENDOR_SPECIFIC.value(), 0);
```

## Metadata

Enable `metadata` to access `ppp_numbers::REGISTRIES` and the crate's `GROUPS`.
