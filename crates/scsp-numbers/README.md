# iana-scsp-numbers

Type-safe, allocation-free Rust bindings for IANA `scsp-numbers` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-scsp-numbers = "0.1.0"
```

```rust
use iana_scsp_numbers::scsp_numbers::ProtocolIds;

assert_eq!(ProtocolIds::ATMARP.value(), 1);
```

## Metadata

Enable `metadata` to access `scsp_numbers::REGISTRIES` and the crate's `GROUPS`.
