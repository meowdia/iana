# iana-bfcp

Type-safe, allocation-free Rust bindings for IANA `bfcp` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-bfcp = "0.1.0"
```

```rust
use iana_bfcp::bfcp;

assert_eq!(bfcp::ID, "bfcp-parameters");
```

## Metadata

Enable `metadata` to access `bfcp::REGISTRIES` and the crate's `GROUPS`.
