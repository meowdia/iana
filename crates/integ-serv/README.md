# iana-integ-serv

Type-safe, allocation-free Rust bindings for IANA `integ-serv` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-integ-serv = "0.1.0"
```

```rust
use iana_integ_serv::integ_serv::ServiceNames;

assert_eq!(ServiceNames::UNUSED_TO_ALLOW_THE_DIRECT_MAPPING_OF_PARAMETER_NAMES_TO_MIB_OBJECT_NAMES.value(), 0);
```

## Metadata

Enable `metadata` to access `integ_serv::REGISTRIES` and the crate's `GROUPS`.
