# iana-kerberos

Type-safe, allocation-free Rust bindings for IANA `kerberos` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-kerberos = { version = "0.1.0", features = ["kerberos-parameters"] }
```

```rust
use iana_kerberos::kerberos::KerberosEncryptionTypeNumbers;

assert_eq!(KerberosEncryptionTypeNumbers::DES_CBC_CRC_DEPRECATED.value(), 1);
```

## Features

No catalogs are enabled by default. Add `metadata` alongside catalog features
to access their `REGISTRIES` and the crate's `GROUPS`.

| Feature | Module |
|---|---|
| [`kerberos-parameters`](https://www.iana.org/assignments/kerberos-parameters/) | `kerberos` |
| [`kerberos-v-gss-api`](https://www.iana.org/assignments/kerberos-v-gss-api/) | `kerberos_v_gss_api` |
