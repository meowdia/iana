# iana-nvo3

Type-safe, allocation-free Rust bindings for IANA `nvo3` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-nvo3 = "0.1.0"
```

```rust
use iana_nvo3::nvo3::GeneveOptionClass;

assert_eq!(GeneveOptionClass::LINUX.value(), 256);
```

## Metadata

Enable `metadata` to access `nvo3::REGISTRIES` and the crate's `GROUPS`.
