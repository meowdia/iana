# iana-gre-parameters

Type-safe, allocation-free Rust bindings for IANA `gre-parameters` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-gre-parameters = "0.1.0"
```

```rust
use iana_gre_parameters::gre::GreVersionNumbers;

assert_eq!(GreVersionNumbers::GRE.value(), 0);
```

## Metadata

Enable `metadata` to access `gre::REGISTRIES` and the crate's `GROUPS`.
