# iana-roughtime

Type-safe, allocation-free Rust bindings for IANA `roughtime` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-roughtime = "0.1.0"
```

```rust
use iana_roughtime::roughtime::RoughtimeVersions;

assert_eq!(RoughtimeVersions::ROUGHTIME_VERSION_1.value(), 1);
```

## Metadata

Enable `metadata` to access `roughtime::REGISTRIES` and the crate's `GROUPS`.
