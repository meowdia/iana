# iana-capwap-parameters

Type-safe, allocation-free Rust bindings for IANA `capwap-parameters` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-capwap-parameters = "0.1.0"
```

```rust
use iana_capwap_parameters::capwap::CapwapMessageTypes;

assert_eq!(CapwapMessageTypes::DISCOVERY_REQUEST.value(), 1);
```

## Metadata

Enable `metadata` to access `capwap::REGISTRIES` and the crate's `GROUPS`.
