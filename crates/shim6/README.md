# iana-shim6

Type-safe, allocation-free Rust bindings for IANA `shim6` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-shim6 = "0.1.0"
```

```rust
use iana_shim6::shim6::Shim6Types;

assert_eq!(Shim6Types::I1_FIRST_ESTABLISHMENT_MESSAGE_FROM_THE_INITIATOR.value(), 1);
```

## Metadata

Enable `metadata` to access `shim6::REGISTRIES` and the crate's `GROUPS`.
