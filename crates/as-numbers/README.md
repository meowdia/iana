# iana-as-numbers

Type-safe, allocation-free Rust bindings for IANA `as-numbers` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-as-numbers = "0.1.0"
```

```rust
use iana_as_numbers::as_numbers;

assert_eq!(as_numbers::ID, "as-numbers");
```
