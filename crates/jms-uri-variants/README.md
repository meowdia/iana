# iana-jms-uri-variants

Type-safe, allocation-free Rust bindings for IANA `jms-uri-variants` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-jms-uri-variants = "0.1.0"
```

```rust
use iana_jms_uri_variants::jms_uri_variants::JmsUriSchemeVariants;

assert_eq!(JmsUriSchemeVariants::JNDI.as_str(), "jndi");
```
