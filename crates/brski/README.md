# iana-brski

Type-safe, allocation-free Rust bindings for IANA `brski` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-brski = "0.1.0"
```

```rust
use iana_brski::brski::PledgeBrskiStatusTelemetryAttributes;

assert_eq!(PledgeBrskiStatusTelemetryAttributes::VERSION.as_str(), "version");
```

## Metadata

Enable `metadata` to access `brski::REGISTRIES` and the crate's `GROUPS`.
