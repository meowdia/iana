# iana-flute-parameters

Type-safe, allocation-free Rust bindings for IANA `flute-parameters` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-flute-parameters = "0.1.0"
```

```rust
use iana_flute_parameters::flute::FluteContentEncodingAlgorithms;

assert_eq!(FluteContentEncodingAlgorithms::V0.value(), 0);
```
