# iana-pa-tnc-parameters

Type-safe, allocation-free Rust bindings for IANA `pa-tnc-parameters` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-pa-tnc-parameters = "0.1.0"
```

```rust
use iana_pa_tnc_parameters::pa_tnc::PaTncAttributeTypes;

assert_eq!(PaTncAttributeTypes::TESTING.as_str(), "Testing");
```
