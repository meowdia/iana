# iana-ntp-parameters

Type-safe, allocation-free Rust bindings for IANA `ntp-parameters` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-ntp-parameters = "0.1.0"
```

```rust
use iana_ntp_parameters::ntp::NtpReferenceIdentifierCodes;

assert_eq!(NtpReferenceIdentifierCodes::GOES.as_str(), "GOES");
```

## Metadata

Enable `metadata` to access `ntp::REGISTRIES` and the crate's `GROUPS`.
