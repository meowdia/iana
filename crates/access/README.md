# iana-access

Type-safe, allocation-free Rust bindings for IANA `access` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-access = "0.1.0"
```

```rust
use iana_access::access_types::AccessTypes;

assert_eq!(AccessTypes::FTP.as_str(), "ftp");
```

## Metadata

Enable `metadata` to access `access_types::REGISTRIES` and the crate's `GROUPS`.
