# iana-params

Type-safe, allocation-free Rust bindings for IANA `params` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-params = "0.1.0"
```

```rust
use iana_params::params::IetfUrnSubNamespaces;

assert_eq!(IetfUrnSubNamespaces::RFC.as_str(), "rfc");
```

## Metadata

Enable `metadata` to access `params::REGISTRIES` and the crate's `GROUPS`.
