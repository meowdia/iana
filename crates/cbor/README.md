# iana-cbor

Type-safe, allocation-free Rust bindings for IANA `cbor` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-cbor = { version = "0.1.0", features = ["cbor-encoded-x509-c509"] }
```

```rust
use iana_cbor::cbor_encoded_x509_c509::C509RdnAttributes;

assert_eq!(C509RdnAttributes::EMAIL_ADDRESS.value(), 0);
```

## Features

No catalogs are enabled by default. Add `metadata` alongside catalog features
to access their `REGISTRIES` and the crate's `GROUPS`.

| Feature | Module |
|---|---|

| [`cbor-tags`](https://www.iana.org/assignments/cbor-tags/) | `cbor_tags` |
