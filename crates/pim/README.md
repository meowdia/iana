# iana-pim

Type-safe, allocation-free Rust bindings for IANA `pim` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-pim = "0.1.0"
```

```rust
use iana_pim::pim::PimHelloOptions;

assert_eq!(PimHelloOptions::HOLD_TIME.value(), 1);
```

## Metadata

Enable `metadata` to access `pim::REGISTRIES` and the crate's `GROUPS`.
