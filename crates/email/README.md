# iana-email

Type-safe, allocation-free Rust bindings for IANA `email` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-email = "0.1.0"
```

```rust
use iana_email::email_auth::EmailAuthenticationMethods;

assert_eq!(EmailAuthenticationMethods::IP_ADDRESS_V4_OR_V6_OF_ORIGINATING_SMTP_CONNECTION.as_str(), "IP address (v4 or v6) of originating SMTP connection");
```

## Metadata

Enable `metadata` to access `email_auth::REGISTRIES` and the crate's `GROUPS`.
