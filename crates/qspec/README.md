# iana-qspec

Type-safe, allocation-free Rust bindings for IANA `qspec` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-qspec = "0.1.0"
```

```rust
use iana_qspec::qspec::ObjectTypes;

assert_eq!(ObjectTypes::V0.value(), 0);
```
