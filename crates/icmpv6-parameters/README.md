# iana-icmpv6-parameters

Type-safe, allocation-free Rust bindings for IANA `icmpv6-parameters` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-icmpv6-parameters = "0.1.0"
```

```rust
use iana_icmpv6_parameters::icmpv6::Icmpv6TypeNumbers;

assert_eq!(Icmpv6TypeNumbers::DESTINATION_UNREACHABLE.value(), 1);
```

## Metadata

Enable `metadata` to access `icmpv6::REGISTRIES` and the crate's `GROUPS`.
