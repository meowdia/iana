# iana-geo

Type-safe, allocation-free Rust bindings for IANA `geo` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-geo = "0.1.0"
```

```rust
use iana_geo::geo_uri::GeoUriParameters;

assert_eq!(GeoUriParameters::CRS.as_str(), "crs");
```

## Metadata

Enable `metadata` to access `geo_uri::REGISTRIES` and the crate's `GROUPS`.
