# iana-gnss

Type-safe, allocation-free Rust bindings for IANA `gnss` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-gnss = "0.1.0"
```

```rust
use iana_gnss::gnss::GlobalNavigationSatelliteSystemGnssTypes;

assert_eq!(GlobalNavigationSatelliteSystemGnssTypes::GLOBAL_POSITIONING_SYSTEM_GPS.as_str(), "Global Positioning System (GPS)");
```

## Metadata

Enable `metadata` to access `gnss::REGISTRIES` and the crate's `GROUPS`.
