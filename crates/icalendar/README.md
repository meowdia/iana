# iana-icalendar

Type-safe, allocation-free Rust bindings for IANA `icalendar` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-icalendar = "0.1.0"
```

```rust
use iana_icalendar::icalendar::Components;

assert_eq!(Components::VCALENDAR.as_str(), "VCALENDAR");
```

## Metadata

Enable `metadata` to access `icalendar::REGISTRIES` and the crate's `GROUPS`.
