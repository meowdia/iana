# iana-proxy-languages

Type-safe, allocation-free Rust bindings for IANA `proxy-languages` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-proxy-languages = "0.1.0"
```

```rust
use iana_proxy_languages::proxy_languages;

assert_eq!(proxy_languages::ID, "proxy-languages");
```

## Metadata

Enable `metadata` to access `proxy_languages::REGISTRIES` and the crate's `GROUPS`.
