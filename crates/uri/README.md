# iana-uri

Type-safe, allocation-free Rust bindings for IANA `uri` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-uri = "0.1.0"
```

```rust
use iana_uri::uri_schemes::UniformResourceIdentifierUriSchemes;

assert_eq!(UniformResourceIdentifierUriSchemes::AAA.as_str(), "aaa");
```

## Metadata

Enable `metadata` to access `uri_schemes::REGISTRIES` and the crate's `GROUPS`.
