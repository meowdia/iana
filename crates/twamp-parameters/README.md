# iana-twamp-parameters

Type-safe, allocation-free Rust bindings for IANA `twamp-parameters` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-twamp-parameters = "0.1.0"
```

```rust
use iana_twamp_parameters::twamp::TwampControlCommandNumbers;

assert_eq!(TwampControlCommandNumbers::FORBIDDEN.value(), 1);
```

## Metadata

Enable `metadata` to access `twamp::REGISTRIES` and the crate's `GROUPS`.
