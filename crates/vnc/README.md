# iana-vnc

Type-safe, allocation-free Rust bindings for IANA `vnc` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-vnc = "0.1.0"
```

```rust
use iana_vnc::vnc_uri::VncUriConnectionChannelTypes;

assert_eq!(VncUriConnectionChannelTypes::STANDARD_TCP.value(), 1);
```

## Metadata

Enable `metadata` to access `vnc_uri::REGISTRIES` and the crate's `GROUPS`.
