# iana-ipp-registrations

Type-safe, allocation-free Rust bindings for IANA `ipp-registrations` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-ipp-registrations = "0.1.0"
```

```rust
use iana_ipp_registrations::ipp_registrations::Objects;

assert_eq!(Objects::DOCUMENT.as_str(), "Document");
```

## Metadata

Enable `metadata` to access `ipp_registrations::REGISTRIES` and the crate's `GROUPS`.
