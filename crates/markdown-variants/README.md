# iana-markdown-variants

Type-safe, allocation-free Rust bindings for IANA `markdown-variants` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-markdown-variants = "0.1.0"
```

```rust
use iana_markdown_variants::markdown_variants::MarkdownVariants;

assert_eq!(MarkdownVariants::MARKDOWN.as_str(), "Markdown");
```

## Metadata

Enable `metadata` to access `markdown_variants::REGISTRIES` and the crate's `GROUPS`.
