# iana-rdap

Type-safe, allocation-free Rust bindings for IANA `rdap` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-rdap = { version = "0.1.0", features = ["rdap-asn"] }
```

```rust
use iana_rdap::rdap_asn;

assert_eq!(rdap_asn::ID, "rdap-asn");
```
