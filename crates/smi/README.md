# iana-smi

Type-safe, allocation-free Rust bindings for IANA `smi` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-smi = "0.1.0"
```

```rust
use iana_smi::smi_numbers::SmiNetworkManagementMgmtCodes;

assert_eq!(SmiNetworkManagementMgmtCodes::MIB.value(), 1);
```

## Metadata

Enable `metadata` to access `smi_numbers::REGISTRIES` and the crate's `GROUPS`.
