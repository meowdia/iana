# iana-ipsec-registry

Type-safe, allocation-free Rust bindings for IANA `ipsec-registry` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-ipsec-registry = "0.1.0"
```

```rust
use iana_ipsec_registry::ipsec_registry::AttributeClasses;

assert_eq!(AttributeClasses::ENCRYPTION_ALGORITHM.value(), 1);
```

## Metadata

Enable `metadata` to access `ipsec_registry::REGISTRIES` and the crate's `GROUPS`.
