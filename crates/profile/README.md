# iana-profile

Type-safe, allocation-free Rust bindings for IANA `profile` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-profile = "0.1.0"
```

```rust
use iana_profile::profile_uris::ProfileUris;

assert_eq!(ProfileUris::EXEMPLARY_PROFILE.as_str(), "Exemplary Profile");
```

## Metadata

Enable `metadata` to access `profile_uris::REGISTRIES` and the crate's `GROUPS`.
