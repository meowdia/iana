# iana-mail

Type-safe, allocation-free Rust bindings for IANA `mail` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-mail = "0.1.0"
```

```rust
use iana_mail::mail_encoding;

assert_eq!(mail_encoding::ID, "mail-encoding");
```

## Metadata

Enable `metadata` to access `mail_encoding::REGISTRIES` and the crate's `GROUPS`.
