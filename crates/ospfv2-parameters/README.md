# iana-ospfv2-parameters

Type-safe, allocation-free Rust bindings for IANA `ospfv2-parameters` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-ospfv2-parameters = "0.1.0"
```

```rust
use iana_ospfv2_parameters::ospfv2::Ospfv2OptionsRegistry8Bits;

assert_eq!(Ospfv2OptionsRegistry8Bits::MT_BIT.value(), 1);
```

## Metadata

Enable `metadata` to access `ospfv2::REGISTRIES` and the crate's `GROUPS`.
