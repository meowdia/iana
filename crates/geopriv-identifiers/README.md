# iana-geopriv-identifiers

Type-safe, allocation-free Rust bindings for IANA `geopriv-identifiers` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-geopriv-identifiers = "0.1.0"
```

```rust
use iana_geopriv_identifiers::geopriv_identifiers::GeoprivIdentifiers;

assert_eq!(GeoprivIdentifiers::URN_IETF_PARAMS_GEOPRIV_RELATIVE_2D.as_str(), "urn:ietf:params:geopriv:relative:2d");
```
