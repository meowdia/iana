# iana-keynote

Type-safe, allocation-free Rust bindings for IANA `keynote` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-keynote = "0.1.0"
```

```rust
use iana_keynote::keynote::KeynotePublicKeyFormatIdentifiers;

assert_eq!(KeynotePublicKeyFormatIdentifiers::RSA_HEX.as_str(), "rsa-hex");
```
