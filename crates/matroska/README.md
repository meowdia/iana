# iana-matroska

Type-safe, allocation-free Rust bindings for IANA `matroska` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-matroska = "0.1.0"
```

```rust
use iana_matroska::matroska::MatroskaElementIds;

assert_eq!(MatroskaElementIds::CHAPTERDISPLAY.value(), 128);
```

## Metadata

Enable `metadata` to access `matroska::REGISTRIES` and the crate's `GROUPS`.
