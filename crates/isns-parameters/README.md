# iana-isns-parameters

Type-safe, allocation-free Rust bindings for IANA `isns-parameters` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-isns-parameters = "0.1.0"
```

```rust
use iana_isns_parameters::isns::BlockStorageProtocols;

assert_eq!(BlockStorageProtocols::V1.value(), 1);
```

## Metadata

Enable `metadata` to access `isns::REGISTRIES` and the crate's `GROUPS`.
