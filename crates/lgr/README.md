# iana-lgr

Type-safe, allocation-free Rust bindings for IANA `lgr` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-lgr = "0.1.0"
```

```rust
use iana_lgr::lgr_dispositions::StandardDispositions;

assert_eq!(StandardDispositions::INVALID.as_str(), "invalid");
```

## Metadata

Enable `metadata` to access `lgr_dispositions::REGISTRIES` and the crate's `GROUPS`.
