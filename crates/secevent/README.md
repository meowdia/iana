# iana-secevent

Type-safe, allocation-free Rust bindings for IANA `secevent` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-secevent = "0.1.0"
```

```rust
use iana_secevent::secevent::SecurityEventTokenErrorCodes;

assert_eq!(SecurityEventTokenErrorCodes::INVALID_REQUEST.as_str(), "invalid_request");
```

## Metadata

Enable `metadata` to access `secevent::REGISTRIES` and the crate's `GROUPS`.
