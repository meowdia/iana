# iana-nntp-parameters

Type-safe, allocation-free Rust bindings for IANA `nntp-parameters` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-nntp-parameters = "0.1.0"
```

```rust
use iana_nntp_parameters::nntp::NntpCapabilityLabels;

assert_eq!(NntpCapabilityLabels::AUTHINFO.as_str(), "AUTHINFO");
```

## Metadata

Enable `metadata` to access `nntp::REGISTRIES` and the crate's `GROUPS`.
