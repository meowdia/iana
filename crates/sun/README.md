# iana-sun

Type-safe, allocation-free Rust bindings for IANA `sun` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-sun = "0.1.0"
```

```rust
use iana_sun::sun_rpc_numbers;

assert_eq!(sun_rpc_numbers::ID, "sun-rpc-numbers");
```

## Metadata

Enable `metadata` to access `sun_rpc_numbers::REGISTRIES` and the crate's `GROUPS`.
