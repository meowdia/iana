# iana-geo-uri-parameters

Type-safe, allocation-free Rust bindings for IANA `geo-uri-parameters` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-geo-uri-parameters = "0.1.0"
```

```rust
use iana_geo_uri_parameters::geo_uri::GeoUriParameters;

assert_eq!(GeoUriParameters::CRS.as_str(), "crs");
```

## Metadata

Enable `metadata` to access `geo_uri::REGISTRIES` and the crate's `GROUPS`.
