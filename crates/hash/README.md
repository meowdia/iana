# iana-hash

Type-safe, allocation-free Rust bindings for IANA `hash` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-hash = "0.1.0"
```

```rust
use iana_hash::hash_function_text_names::HashFunctionTextualNames;

assert_eq!(HashFunctionTextualNames::MD2.as_str(), "\"md2\"");
```

## Metadata

Enable `metadata` to access `hash_function_text_names::REGISTRIES` and the crate's `GROUPS`.
