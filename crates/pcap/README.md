# iana-pcap

Type-safe, allocation-free Rust bindings for IANA `pcap` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-pcap = "0.1.0"
```

```rust
use iana_pcap::pcap::PcapRelatedLinktypes;

assert_eq!(PcapRelatedLinktypes::BSD_LOOPBACK_ENCAPSULATION.value(), 0);
```

## Metadata

Enable `metadata` to access `pcap::REGISTRIES` and the crate's `GROUPS`.
