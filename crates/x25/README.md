# iana-x25

Type-safe, allocation-free Rust bindings for IANA `x25` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-x25 = "0.1.0"
```

```rust
use iana_x25::x25_type_numbers;

assert_eq!(x25_type_numbers::ID, "x25-type-numbers");
```
