# iana-rohc

Type-safe, allocation-free Rust bindings for IANA `rohc` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-rohc = { version = "0.1.0", features = ["rohc-pro-ids"] }
```

```rust
use iana_rohc::rohc_pro_ids;

assert_eq!(rohc_pro_ids::ID, "rohc-pro-ids");
```

## Features

No catalogs are enabled by default. Add `metadata` alongside catalog features
to access their `REGISTRIES` and the crate's `GROUPS`.

| Feature | Module |
|---|---|
| [`rohc-pro-ids`](https://www.iana.org/assignments/rohc-pro-ids/) | `rohc_pro_ids` |
| [`rohc-sub-ids`](https://www.iana.org/assignments/rohc-sub-ids/) | `rohc_sub_ids` |
