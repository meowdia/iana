# iana-performance

Type-safe, allocation-free Rust bindings for IANA `performance` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-performance = "0.1.0"
```

```rust
use iana_performance::performance_metrics::PerformanceMetricsRegistry;

assert_eq!(PerformanceMetricsRegistry::RESERVED.as_str(), "Reserved");
```

## Metadata

Enable `metadata` to access `performance_metrics::REGISTRIES` and the crate's `GROUPS`.
