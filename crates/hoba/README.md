# iana-hoba

Type-safe, allocation-free Rust bindings for IANA `hoba` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-hoba = { version = "0.1.0", features = ["hoba-device-identifiers"] }
```

```rust
use iana_hoba::hoba_device_identifiers::HobaDeviceIdentifierTypes;

assert_eq!(HobaDeviceIdentifierTypes::AN_UNFORMATTED_STRING_AT_THE_USER_S_UA_S_WHIM.value(), 0);
```
