# iana-message

Type-safe, allocation-free Rust bindings for IANA `message` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-message = { version = "0.1.0", features = ["message-header-types"] }
```

```rust
use iana_message::message_header_types::InternetMessageContentTypes;

assert_eq!(InternetMessageContentTypes::FAX_MESSAGE.as_str(), "fax-message");
```

## Features

No catalogs are enabled by default. Add `metadata` alongside catalog features
to access their `REGISTRIES` and the crate's `GROUPS`.
