# iana-udpstp

Type-safe, allocation-free Rust bindings for IANA `udpstp` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-udpstp = "0.1.0"
```

```rust
use iana_udpstp::udpstp::PduIdentifier;

assert_eq!(PduIdentifier::TEST_SETUP_PDU.value(), 44257);
```

## Metadata

Enable `metadata` to access `udpstp::REGISTRIES` and the crate's `GROUPS`.
