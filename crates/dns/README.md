# iana-dns

Type-safe, allocation-free Rust bindings for IANA `dns` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-dns = { version = "0.1.0", features = ["dns-parameters"] }
```

```rust
use iana_dns::dns::DnsClasses;

assert_eq!(DnsClasses::INTERNET_IN.value(), 1);
```

## Features

No catalogs are enabled by default. Add `metadata` alongside catalog features
to access their `REGISTRIES` and the crate's `GROUPS`.

| Feature | Module |
|---|---|
| [`dns-key-rr`](https://www.iana.org/assignments/dns-key-rr/) | `dns_key_rr` |
| [`dns-parameters`](https://www.iana.org/assignments/dns-parameters/) | `dns` |
| [`dns-sec-alg-numbers`](https://www.iana.org/assignments/dns-sec-alg-numbers/) | `dns_sec_alg_numbers` |
| [`dns-sshfp-rr-parameters`](https://www.iana.org/assignments/dns-sshfp-rr-parameters/) | `dns_sshfp_rr` |
| [`dns-svcb`](https://www.iana.org/assignments/dns-svcb/) | `dns_svcb` |
