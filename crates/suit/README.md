# iana-suit

Type-safe, allocation-free Rust bindings for IANA `suit` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-suit = "0.1.0"
```

```rust
use iana_suit::suit;

assert_eq!(suit::ID, "suit");
```
