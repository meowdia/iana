# iana-iesg

Type-safe, allocation-free Rust bindings for IANA `iesg` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-iesg = "0.1.0"
```

```rust
use iana_iesg::iesg_recognized_organizations;

assert_eq!(iesg_recognized_organizations::ID, "iesg-recognized-organizations");
```

## Metadata

Enable `metadata` to access `iesg_recognized_organizations::REGISTRIES` and the crate's `GROUPS`.
