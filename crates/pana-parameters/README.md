# iana-pana-parameters

Type-safe, allocation-free Rust bindings for IANA `pana-parameters` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-pana-parameters = "0.1.0"
```

```rust
use iana_pana_parameters::pana::MessageTypes;

assert_eq!(MessageTypes::PANA_CLIENT_INITIATION.value(), 1);
```

## Metadata

Enable `metadata` to access `pana::REGISTRIES` and the crate's `GROUPS`.
