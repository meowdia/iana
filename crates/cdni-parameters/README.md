# iana-cdni-parameters

Type-safe, allocation-free Rust bindings for IANA `cdni-parameters` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-cdni-parameters = "0.1.0"
```

```rust
use iana_cdni_parameters::cdni::CdniPayloadTypes;

assert_eq!(CdniPayloadTypes::CI_TRIGGER_COMMAND.as_str(), "ci-trigger-command");
```

## Metadata

Enable `metadata` to access `cdni::REGISTRIES` and the crate's `GROUPS`.
