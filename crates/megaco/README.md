# iana-megaco

Type-safe, allocation-free Rust bindings for IANA `megaco` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-megaco = "0.1.0"
```

```rust
use iana_megaco::megaco_h248::TabulationOfPublicPackages;

assert_eq!(TabulationOfPublicPackages::G.value(), 1);
```
