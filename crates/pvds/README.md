# iana-pvds

Type-safe, allocation-free Rust bindings for IANA `pvds` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-pvds = "0.1.0"
```

```rust
use iana_pvds::pvds::AdditionalInformationPvdKeys;

assert_eq!(AdditionalInformationPvdKeys::IDENTIFIER.as_str(), "identifier");
```

## Metadata

Enable `metadata` to access `pvds::REGISTRIES` and the crate's `GROUPS`.
