# iana-safi

Type-safe, allocation-free Rust bindings for IANA `safi` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-safi = "0.1.0"
```

```rust
use iana_safi::safi_namespace::SafiValues;

assert_eq!(SafiValues::NETWORK_LAYER_REACHABILITY_INFORMATION_USED_FOR_UNICAST_FORWARDING.value(), 1);
```

## Metadata

Enable `metadata` to access `safi_namespace::REGISTRIES` and the crate's `GROUPS`.
