# iana-iana

Type-safe, allocation-free Rust bindings for IANA `iana` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-iana = { version = "0.1.0", features = ["iana-as-numbers-special-registry"] }
```

```rust
use iana_iana::iana_as_numbers_special_registry::SpecialPurposeAsNumbers;

assert_eq!(SpecialPurposeAsNumbers::USED_BY_THE_AS112_PROJECT_TO_SINK_MISDIRECTED_DNS_QUERIES_SEE.value(), 112);
```
