# iana-manet-parameters

Type-safe, allocation-free Rust bindings for IANA `manet-parameters` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-manet-parameters = "0.1.0"
```

```rust
use iana_manet_parameters::manet::MessageTypes;

assert_eq!(MessageTypes::HELLO_LOCAL_SIGNALING.value(), 0);
```

## Metadata

Enable `metadata` to access `manet::REGISTRIES` and the crate's `GROUPS`.
