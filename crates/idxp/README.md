# iana-idxp

Type-safe, allocation-free Rust bindings for IANA `idxp` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-idxp = "0.1.0"
```

```rust
use iana_idxp::idxp_options::IdxpOptions;

assert_eq!(IdxpOptions::CHANNELPRIORITY.as_str(), "channelPriority");
```

## Metadata

Enable `metadata` to access `idxp_options::REGISTRIES` and the crate's `GROUPS`.
