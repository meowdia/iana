# iana-jose

Type-safe, allocation-free Rust bindings for IANA `jose` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-jose = "0.2.0"
```

```rust
use iana_jose::jose::JsonWebSignatureAndEncryptionHeaderParameters;

assert_eq!(JsonWebSignatureAndEncryptionHeaderParameters::ALG.as_str(), "alg");
```

## Metadata

Enable `metadata` to access `jose::REGISTRIES` and the crate's `GROUPS`.
