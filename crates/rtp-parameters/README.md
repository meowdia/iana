# iana-rtp-parameters

Type-safe, allocation-free Rust bindings for IANA `rtp-parameters` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-rtp-parameters = "0.1.0"
```

```rust
use iana_rtp_parameters::rtp::RtpPayloadTypesPtForStandardAudioAndVideoEncodingsClosed;

assert_eq!(RtpPayloadTypesPtForStandardAudioAndVideoEncodingsClosed::PCMU.value(), 0);
```

## Metadata

Enable `metadata` to access `rtp::REGISTRIES` and the crate's `GROUPS`.
