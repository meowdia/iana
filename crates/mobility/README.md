# iana-mobility

Type-safe, allocation-free Rust bindings for IANA `mobility` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-mobility = "0.1.0"
```

```rust
use iana_mobility::mobility::MobilityHeaderTypesForTheMhTypeFieldInTheMobilityHeader;

assert_eq!(MobilityHeaderTypesForTheMhTypeFieldInTheMobilityHeader::BINDING_REFRESH_REQUEST.value(), 0);
```
