# iana-iotp-codes

Type-safe, allocation-free Rust bindings for IANA `iotp-codes` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-iotp-codes = "0.1.0"
```

```rust
use iana_iotp_codes::iotp_codes::AlgorithmName;

assert_eq!(AlgorithmName::SHA1.as_str(), "\"sha1\"");
```

## Metadata

Enable `metadata` to access `iotp_codes::REGISTRIES` and the crate's `GROUPS`.
