# iana-nsh

Type-safe, allocation-free Rust bindings for IANA `nsh` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-nsh = "0.1.0"
```

```rust
use iana_nsh::nsh::NshBaseHeaderBits;

assert_eq!(NshBaseHeaderBits::O_OAM_BIT.value(), 2);
```

## Metadata

Enable `metadata` to access `nsh::REGISTRIES` and the crate's `GROUPS`.
