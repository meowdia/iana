# iana-os-specific-parameters

Type-safe, allocation-free Rust bindings for IANA `os-specific-parameters` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-os-specific-parameters = "0.1.0"
```

```rust
use iana_os_specific_parameters::os_specific::OsSpecificFactNames;

assert_eq!(OsSpecificFactNames::UNIX.as_str(), "Unix");
```

## Metadata

Enable `metadata` to access `os_specific::REGISTRIES` and the crate's `GROUPS`.
