# iana-coap-eap

Type-safe, allocation-free Rust bindings for IANA `coap-eap` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-coap-eap = "0.1.0"
```

```rust
use iana_coap_eap::coap_eap::CoapEapInformationElements;

assert_eq!(CoapEapInformationElements::UNASSIGNED.as_str(), "Unassigned");
```

## Metadata

Enable `metadata` to access `coap_eap::REGISTRIES` and the crate's `GROUPS`.
