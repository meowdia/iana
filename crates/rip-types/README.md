# iana-rip-types

Type-safe, allocation-free Rust bindings for IANA `rip-types` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-rip-types = "0.1.0"
```

```rust
use iana_rip_types::rip_types::RipCommands;

assert_eq!(RipCommands::INVALID.value(), 0);
```

## Metadata

Enable `metadata` to access `rip_types::REGISTRIES` and the crate's `GROUPS`.
