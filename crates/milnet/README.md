# iana-milnet

Type-safe, allocation-free Rust bindings for IANA `milnet` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-milnet = "0.1.0"
```

```rust
use iana_milnet::milnet::MilnetLinkNumbers;

assert_eq!(MilnetLinkNumbers::XEROX_NS_IDP.value(), 150);
```

## Metadata

Enable `metadata` to access `milnet::REGISTRIES` and the crate's `GROUPS`.
