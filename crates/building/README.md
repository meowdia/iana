# iana-building

Type-safe, allocation-free Rust bindings for IANA `building` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-building = "0.1.0"
```

```rust
use iana_building::building_blocks;

assert_eq!(building_blocks::ID, "building-blocks");
```

## Metadata

Enable `metadata` to access `building_blocks::REGISTRIES` and the crate's `GROUPS`.
