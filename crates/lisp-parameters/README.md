# iana-lisp-parameters

Type-safe, allocation-free Rust bindings for IANA `lisp-parameters` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-lisp-parameters = "0.1.0"
```

```rust
use iana_lisp_parameters::lisp::LispActValues;

assert_eq!(LispActValues::THE_MAP_CACHE_IS_KEPT_ALIVE_AND_NO_PACKET_ENCAPSULATION_OCCURS.value(), 0);
```
