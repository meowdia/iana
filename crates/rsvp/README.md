# iana-rsvp

Type-safe, allocation-free Rust bindings for IANA `rsvp` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-rsvp = { version = "0.1.0", features = ["rsvp-parameters"] }
```

```rust
use iana_rsvp::rsvp::MessageTypes;

assert_eq!(MessageTypes::PATH.value(), 1);
```

## Features

No catalogs are enabled by default. Add `metadata` alongside catalog features
to access their `REGISTRIES` and the crate's `GROUPS`.

| Feature | Module |
|---|---|
| [`rsvp-parameters`](https://www.iana.org/assignments/rsvp-parameters/) | `rsvp` |
| [`rsvp-te-oam`](https://www.iana.org/assignments/rsvp-te-oam/) | `rsvp_te_oam` |
| [`rsvp-te-parameters`](https://www.iana.org/assignments/rsvp-te-parameters/) | `rsvp_te` |
