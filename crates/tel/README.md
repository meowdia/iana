# iana-tel

Type-safe, allocation-free Rust bindings for IANA `tel` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-tel = "0.1.0"
```

```rust
use iana_tel::tel_uri;

assert_eq!(tel_uri::ID, "tel-uri-parameters");
```

## Metadata

Enable `metadata` to access `tel_uri::REGISTRIES` and the crate's `GROUPS`.
