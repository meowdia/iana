# iana-trailer-types

Type-safe, allocation-free Rust bindings for IANA `trailer-types` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-trailer-types = "0.1.0"
```

```rust
use iana_trailer_types::trailer_types;

assert_eq!(trailer_types::ID, "trailer-types");
```
