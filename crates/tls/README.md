# iana-tls

Type-safe, allocation-free Rust bindings for IANA `tls` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-tls = { version = "0.1.0", features = ["tls-parameters"] }
```

```rust
use iana_tls::tls::TlsClientcertificatetypeIdentifiers;

assert_eq!(TlsClientcertificatetypeIdentifiers::RSA_SIGN.value(), 1);
```

## Features

No catalogs are enabled by default. Add `metadata` alongside catalog features
to access their `REGISTRIES` and the crate's `GROUPS`.

| Feature | Module |
|---|---|
| [`tls-ech-configuration-extensions`](https://www.iana.org/assignments/tls-ech-configuration-extensions/) | `tls_ech_configuration_extensions` |
| [`tls-extensiontype-values`](https://www.iana.org/assignments/tls-extensiontype-values/) | `tls_extensiontype_values` |
| [`tls-parameters`](https://www.iana.org/assignments/tls-parameters/) | `tls` |
