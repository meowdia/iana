# iana-dncp

Type-safe, allocation-free Rust bindings for IANA `dncp` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-dncp = "0.1.0"
```

```rust
use iana_dncp::dncp_registry::DncpTlvTypes;

assert_eq!(DncpTlvTypes::REQUEST_NETWORK_STATE.value(), 1);
```

## Metadata

Enable `metadata` to access `dncp_registry::REGISTRIES` and the crate's `GROUPS`.
