# iana-enum

Type-safe, allocation-free Rust bindings for IANA `enum` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-enum = "0.1.0"
```

```rust
use iana_enum::enum_services;

assert_eq!(enum_services::ID, "enum-services");
```

Enable `metadata` to access `enum_services::REGISTRIES` and the crate's `GROUPS`.
