# iana-sdf

Type-safe, allocation-free Rust bindings for IANA `sdf` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-sdf = "0.1.0"
```

```rust
use iana_sdf::sdf::SdfQualityNames;

assert_eq!(SdfQualityNames::COMMENT.as_str(), "$comment");
```

## Metadata

Enable `metadata` to access `sdf::REGISTRIES` and the crate's `GROUPS`.
