# iana-pwe3-parameters

Type-safe, allocation-free Rust bindings for IANA `pwe3-parameters` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-pwe3-parameters = "0.1.0"
```

```rust
use iana_pwe3_parameters::pwe3::PseudowireSwitchingPointPeSubTlvType;

assert_eq!(PseudowireSwitchingPointPeSubTlvType::PWID_OF_LAST_PW_SEGMENT_TRAVERSED.value(), 1);
```
