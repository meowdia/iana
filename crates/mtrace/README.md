# iana-mtrace

Type-safe, allocation-free Rust bindings for IANA `mtrace` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-mtrace = "0.1.0"
```

```rust
use iana_mtrace::mtrace::Mtrace2ForwardingCodes;

assert_eq!(Mtrace2ForwardingCodes::NO_ERROR.value(), 0);
```

## Metadata

Enable `metadata` to access `mtrace::REGISTRIES` and the crate's `GROUPS`.
