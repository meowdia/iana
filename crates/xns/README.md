# iana-xns

Type-safe, allocation-free Rust bindings for IANA `xns` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-xns = "0.1.0"
```

```rust
use iana_xns::xns_protocol_types::AssignedWellKnownSocketNumbers;

assert_eq!(AssignedWellKnownSocketNumbers::ROUTING_INFORMATION.value(), 1);
```

## Metadata

Enable `metadata` to access `xns_protocol_types::REGISTRIES` and the crate's `GROUPS`.
