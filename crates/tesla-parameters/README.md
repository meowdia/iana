# iana-tesla-parameters

Type-safe, allocation-free Rust bindings for IANA `tesla-parameters` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-tesla-parameters = "0.1.0"
```

```rust
use iana_tesla_parameters::tesla::CryptographicPseudoRandomFunctionTeslaPrfValues;

assert_eq!(CryptographicPseudoRandomFunctionTeslaPrfValues::HMAC_SHA1.value(), 0);
```

## Metadata

Enable `metadata` to access `tesla::REGISTRIES` and the crate's `GROUPS`.
