# iana-acl

Type-safe, allocation-free Rust bindings for IANA `acl` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-acl = "0.1.0"
```

```rust
use iana_acl::acl_tls::AclTlsVersionCodes;

assert_eq!(AclTlsVersionCodes::TLS_VERSION_1_2.value(), 1);
```

## Metadata

Enable `metadata` to access `acl_tls::REGISTRIES` and the crate's `GROUPS`.
