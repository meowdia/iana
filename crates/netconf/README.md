# iana-netconf

Type-safe, allocation-free Rust bindings for IANA `netconf` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-netconf = "0.1.0"
```

```rust
use iana_netconf::netconf_capability_urns;

assert_eq!(netconf_capability_urns::ID, "netconf-capability-urns");
```

## Metadata

Enable `metadata` to access `netconf_capability_urns::REGISTRIES` and the crate's `GROUPS`.
