# iana-ips-protocols

Type-safe, allocation-free Rust bindings for IANA `ips-protocols` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-ips-protocols = "0.1.0"
```

```rust
use iana_ips_protocols::ips_protocols::ProtocolProtocolNumberField;

assert_eq!(ProtocolProtocolNumberField::FCIP_FIBRE_CHANNEL_OVER_TCP_IP_ENCAPSULATING_PROTOCOL.value(), 1);
```

## Metadata

Enable `metadata` to access `ips_protocols::REGISTRIES` and the crate's `GROUPS`.
