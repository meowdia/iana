# iana-held-parameters

Type-safe, allocation-free Rust bindings for IANA `held-parameters` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-held-parameters = "0.1.0"
```

```rust
use iana_held_parameters::held;

assert_eq!(held::ID, "held-parameters");
```
