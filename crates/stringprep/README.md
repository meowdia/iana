# iana-stringprep

Type-safe, allocation-free Rust bindings for IANA `stringprep` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-stringprep = "0.1.0"
```

```rust
use iana_stringprep::stringprep_profiles::StringprepProfiles;

assert_eq!(StringprepProfiles::ISCSI.as_str(), "iSCSI");
```

## Metadata

Enable `metadata` to access `stringprep_profiles::REGISTRIES` and the crate's `GROUPS`.
