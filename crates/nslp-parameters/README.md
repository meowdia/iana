# iana-nslp-parameters

Type-safe, allocation-free Rust bindings for IANA `nslp-parameters` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-nslp-parameters = "0.1.0"
```

```rust
use iana_nslp_parameters::nslp::QosNslpMessageTypes;

assert_eq!(QosNslpMessageTypes::RESERVE.value(), 1);
```

## Metadata

Enable `metadata` to access `nslp::REGISTRIES` and the crate's `GROUPS`.
