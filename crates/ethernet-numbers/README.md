# iana-ethernet-numbers

Type-safe, allocation-free Rust bindings for IANA `ethernet-numbers` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-ethernet-numbers = "0.1.0"
```

```rust
use iana_ethernet_numbers::ethernet_numbers::IanaUnicast48BitMacAddresses;

assert_eq!(IanaUnicast48BitMacAddresses::V00_01_00_TO_00_01_FF.as_str(), "00-01-00 to 00-01-FF");
```

## Metadata

Enable `metadata` to access `ethernet_numbers::REGISTRIES` and the crate's `GROUPS`.
