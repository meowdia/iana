# iana-socks-methods

Type-safe, allocation-free Rust bindings for IANA `socks-methods` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-socks-methods = "0.1.0"
```

```rust
use iana_socks_methods::socks_methods::SocksReplyCodes;

assert_eq!(SocksReplyCodes::SUCCEEDED.value(), 0);
```
