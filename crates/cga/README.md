# iana-cga

Type-safe, allocation-free Rust bindings for IANA `cga` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-cga = "0.1.0"
```

```rust
use iana_cga::cga_message_types::CgaSec;

assert_eq!(CgaSec::SHA_1_0HASH2BITS.value(), 0);
```

## Metadata

Enable `metadata` to access `cga_message_types::REGISTRIES` and the crate's `GROUPS`.
