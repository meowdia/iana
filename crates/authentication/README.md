# iana-authentication

Type-safe, allocation-free Rust bindings for IANA `authentication` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-authentication = { version = "0.1.0", features = ["authentication-cryptographic-protocol-id"] }
```

```rust
use iana_authentication::authentication_cryptographic_protocol_id::CryptographicProtocolId;

assert_eq!(CryptographicProtocolId::OSPFV3.value(), 1);
```
