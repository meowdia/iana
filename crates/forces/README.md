# iana-forces

Type-safe, allocation-free Rust bindings for IANA `forces` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-forces = "0.1.0"
```

```rust
use iana_forces::forces::MessageTypes;

assert_eq!(MessageTypes::ASSOCIATIONSETUP.value(), 1);
```
