# iana-eappotp

Type-safe, allocation-free Rust bindings for IANA `eappotp` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-eappotp = "0.1.0"
```

```rust
use iana_eappotp::eappotp_identifiers;

assert_eq!(eappotp_identifiers::ID, "eappotp-identifiers");
```

## Metadata

Enable `metadata` to access `eappotp_identifiers::REGISTRIES` and the crate's `GROUPS`.
