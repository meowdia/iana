# iana-ace

Type-safe, allocation-free Rust bindings for IANA `ace` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-ace = "0.1.0"
```

```rust
use iana_ace::ace::OscoreSecurityContextParameters;

assert_eq!(OscoreSecurityContextParameters::RESERVED_FOR_PRIVATE_USE.as_str(), "Reserved for Private Use");
```

## Metadata

Enable `metadata` to access `ace::REGISTRIES` and the crate's `GROUPS`.
