# iana-dane-parameters

Type-safe, allocation-free Rust bindings for IANA `dane-parameters` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-dane-parameters = "0.1.0"
```

```rust
use iana_dane_parameters::dane::TlsaCertificateUsages;

assert_eq!(TlsaCertificateUsages::CA_CONSTRAINT.value(), 0);
```

## Metadata

Enable `metadata` to access `dane::REGISTRIES` and the crate's `GROUPS`.
