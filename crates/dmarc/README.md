# iana-dmarc

Type-safe, allocation-free Rust bindings for IANA `dmarc` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-dmarc = "0.1.0"
```

```rust
use iana_dmarc::dmarc::DmarcTags;

assert_eq!(DmarcTags::ADKIM.as_str(), "adkim");
```

## Metadata

Enable `metadata` to access `dmarc::REGISTRIES` and the crate's `GROUPS`.
