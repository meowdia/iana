# iana-6tisch

Type-safe, allocation-free Rust bindings for IANA `6tisch` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-6tisch = "0.1.0"
```

```rust
use iana_6tisch::v6tisch::V6pVersionNumbers;

assert_eq!(V6pVersionNumbers::V0.value(), 0);
```
