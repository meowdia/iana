# iana-drip

Type-safe, allocation-free Rust bindings for IANA `drip` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-drip = "0.1.0"
```

```rust
use iana_drip::drip::HierarchicalHitHhitPrefixes;

assert_eq!(HierarchicalHitHhitPrefixes::V2001_30_28.as_str(), "2001:30::/28");
```

## Metadata

Enable `metadata` to access `drip::REGISTRIES` and the crate's `GROUPS`.
