# iana-posh-service-names

Type-safe, allocation-free Rust bindings for IANA `posh-service-names` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-posh-service-names = "0.1.0"
```

```rust
use iana_posh_service_names::posh_service_names::PoshServiceNames;

assert_eq!(PoshServiceNames::XMPP_CLIENT.as_str(), "xmpp-client");
```

## Metadata

Enable `metadata` to access `posh_service_names::REGISTRIES` and the crate's `GROUPS`.
