# iana-yang

Type-safe, allocation-free Rust bindings for IANA `yang` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-yang = { version = "0.1.0", features = ["yang-parameters"] }
```

```rust
use iana_yang::yang::YangModuleNames;

assert_eq!(YangModuleNames::IANA_BFD_TYPES.as_str(), "iana-bfd-types");
```

## Features

No catalogs are enabled by default. Add `metadata` alongside catalog features
to access their `REGISTRIES` and the crate's `GROUPS`.

| Feature | Module |
|---|---|
| [`yang-geographic-location`](https://www.iana.org/assignments/yang-geographic-location/) | `yang_geographic_location` |
| [`yang-module-tags`](https://www.iana.org/assignments/yang-module-tags/) | `yang_module_tags` |
| [`yang-parameters`](https://www.iana.org/assignments/yang-parameters/) | `yang` |
| [`yang-sid`](https://www.iana.org/assignments/yang-sid/) | `yang_sid` |
