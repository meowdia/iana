# iana-smtp

Type-safe, allocation-free Rust bindings for IANA `smtp` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-smtp = { version = "0.1.0", features = ["smtp"] }
```

```rust
use iana_smtp::smtp::SmtpServiceExtensions;

assert_eq!(SmtpServiceExtensions::SEND.as_str(), "SEND");
```

## Features

No catalogs are enabled by default. Add `metadata` alongside catalog features
to access their `REGISTRIES` and the crate's `GROUPS`.

| Feature | Module |
|---|---|
| [`smtp`](https://www.iana.org/assignments/smtp/) | `smtp` |
