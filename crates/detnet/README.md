# iana-detnet

Type-safe, allocation-free Rust bindings for IANA `detnet` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-detnet = "0.1.0"
```

```rust
use iana_detnet::detnet_ach_flags;

assert_eq!(detnet_ach_flags::ID, "detnet-ach-flags");
```

## Metadata

Enable `metadata` to access `detnet_ach_flags::REGISTRIES` and the crate's `GROUPS`.
