# iana-alto

Type-safe, allocation-free Rust bindings for IANA `alto` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-alto = "0.1.0"
```

```rust
use iana_alto::alto_protocol::AltoCostModes;

assert_eq!(AltoCostModes::NUMERICAL.as_str(), "numerical");
```

## Metadata

Enable `metadata` to access `alto_protocol::REGISTRIES` and the crate's `GROUPS`.
