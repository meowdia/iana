# iana-gdoi-payloads

Type-safe, allocation-free Rust bindings for IANA `gdoi-payloads` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-gdoi-payloads = "0.1.0"
```

```rust
use iana_gdoi_payloads::gdoi_payloads::GdoiIdPayloadTypeValues;

assert_eq!(GdoiIdPayloadTypeValues::ID_KEY_ID.value(), 11);
```

## Metadata

Enable `metadata` to access `gdoi_payloads::REGISTRIES` and the crate's `GROUPS`.
