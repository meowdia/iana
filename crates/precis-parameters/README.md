# iana-precis-parameters

Type-safe, allocation-free Rust bindings for IANA `precis-parameters` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-precis-parameters = "0.1.0"
```

```rust
use iana_precis_parameters::precis::PrecisBaseClasses;

assert_eq!(PrecisBaseClasses::FREEFORMCLASS.as_str(), "FreeformClass");
```

## Metadata

Enable `metadata` to access `precis::REGISTRIES` and the crate's `GROUPS`.
