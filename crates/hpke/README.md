# iana-hpke

Type-safe, allocation-free Rust bindings for IANA `hpke` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-hpke = "0.1.0"
```

```rust
use iana_hpke::hpke::HpkeKemIdentifiers;

assert_eq!(HpkeKemIdentifiers::V0X0000.value(), 0);
```

## Metadata

Enable `metadata` to access `hpke::REGISTRIES` and the crate's `GROUPS`.
