# iana-named

Type-safe, allocation-free Rust bindings for IANA `named` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-named = "0.1.0"
```

```rust
use iana_named::named_information::NamedInformationUriParameterDefinitions;

assert_eq!(NamedInformationUriParameterDefinitions::CT.as_str(), "ct");
```

## Metadata

Enable `metadata` to access `named_information::REGISTRIES` and the crate's `GROUPS`.
