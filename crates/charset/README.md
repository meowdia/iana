# iana-charset

Type-safe, allocation-free Rust bindings for IANA `charset` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-charset = { version = "0.1.0", features = ["charset-info"] }
```

```rust
use iana_charset::charset_info;

assert_eq!(charset_info::ID, "charset-info");
```

## Features

No catalogs are enabled by default. Add `metadata` alongside catalog features
to access their `REGISTRIES` and the crate's `GROUPS`.

| Feature | Module |
|---|---|
| [`charset-info`](https://www.iana.org/assignments/charset-info/) | `charset_info` |
| [`charset-reg`](https://www.iana.org/assignments/charset-reg/) | `charset_reg` |
