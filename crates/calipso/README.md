# iana-calipso

Type-safe, allocation-free Rust bindings for IANA `calipso` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-calipso = "0.1.0"
```

```rust
use iana_calipso::calipso::CalipsoDomainOfInterpretationDoi;

assert_eq!(CalipsoDomainOfInterpretationDoi::V0_0_0_0.as_str(), "0:0:0:0");
```

## Metadata

Enable `metadata` to access `calipso::REGISTRIES` and the crate's `GROUPS`.
