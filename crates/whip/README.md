# iana-whip

Type-safe, allocation-free Rust bindings for IANA `whip` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-whip = "0.1.0"
```

```rust
use iana_whip::whip::WebrtcHttpIngestionProtocolWhipUrns;

assert_eq!(WebrtcHttpIngestionProtocolWhipUrns::URN_IETF_PARAMS_WHIP_EXT.as_str(), "urn:ietf:params:whip:ext");
```
