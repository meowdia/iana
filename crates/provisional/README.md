# iana-provisional

Type-safe, allocation-free Rust bindings for IANA `provisional` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-provisional = "0.1.0"
```

```rust
use iana_provisional::provisional_standard_media_types::ProvisionalStandardMediaTypeRegistry;

assert_eq!(ProvisionalStandardMediaTypeRegistry::APPLICATION_ODM_JSON.as_str(), "application/odm+json");
```

## Metadata

Enable `metadata` to access `provisional_standard_media_types::REGISTRIES` and the crate's `GROUPS`.
