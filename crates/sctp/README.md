# iana-sctp

Type-safe, allocation-free Rust bindings for IANA `sctp` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-sctp = "0.1.0"
```

```rust
use iana_sctp::sctp::ChunkTypes;

assert_eq!(ChunkTypes::PAYLOAD_DATA_DATA.value(), 0);
```

## Metadata

Enable `metadata` to access `sctp::REGISTRIES` and the crate's `GROUPS`.
