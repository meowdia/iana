# iana-webfinger

Type-safe, allocation-free Rust bindings for IANA `webfinger` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-webfinger = "0.1.0"
```

```rust
use iana_webfinger::webfinger;

assert_eq!(webfinger::ID, "webfinger");
```

## Metadata

Enable `metadata` to access `webfinger::REGISTRIES` and the crate's `GROUPS`.
