# iana-content-security-policy-directives

Type-safe, allocation-free Rust bindings for IANA `content-security-policy-directives` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-content-security-policy-directives = "0.1.0"
```

```rust
use iana_content_security_policy_directives::content_security_policy_directives::ContentSecurityPolicyDirectives;

assert_eq!(ContentSecurityPolicyDirectives::BASE_URI.as_str(), "base-uri");
```
