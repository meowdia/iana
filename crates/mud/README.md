# iana-mud

Type-safe, allocation-free Rust bindings for IANA `mud` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-mud = "0.1.0"
```

```rust
use iana_mud::mud::MudWellKnownUniformResourceNameUrn;

assert_eq!(MudWellKnownUniformResourceNameUrn::URN_IETF_PARAMS_MUD_DNS.as_str(), "urn:ietf:params:mud:dns");
```

## Metadata

Enable `metadata` to access `mud::REGISTRIES` and the crate's `GROUPS`.
