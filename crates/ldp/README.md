# iana-ldp

Type-safe, allocation-free Rust bindings for IANA `ldp` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-ldp = "0.1.0"
```

```rust
use iana_ldp::ldp_namespaces::MessageTypeNameSpace;

assert_eq!(MessageTypeNameSpace::NOTIFICATION.value(), 1);
```

## Metadata

Enable `metadata` to access `ldp_namespaces::REGISTRIES` and the crate's `GROUPS`.
