# iana-c

Type-safe, allocation-free Rust bindings for IANA `c` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-c = "0.1.0"
```

```rust
use iana_c::c_dns::CDnsTransports;

assert_eq!(CDnsTransports::UDP.value(), 0);
```

## Metadata

Enable `metadata` to access `c_dns::REGISTRIES` and the crate's `GROUPS`.
