# iana-wesp-flags

Type-safe, allocation-free Rust bindings for IANA `wesp-flags` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-wesp-flags = "0.1.0"
```

```rust
use iana_wesp_flags::wesp_flags::WespFlags;

assert_eq!(WespFlags::V2.value(), 2);
```

## Metadata

Enable `metadata` to access `wesp_flags::REGISTRIES` and the crate's `GROUPS`.
