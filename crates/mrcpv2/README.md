# iana-mrcpv2

Type-safe, allocation-free Rust bindings for IANA `mrcpv2` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-mrcpv2 = "0.1.0"
```

```rust
use iana_mrcpv2::mrcpv2::Mrcpv2ResourceTypes;

assert_eq!(Mrcpv2ResourceTypes::SPEECHRECOG.as_str(), "speechrecog");
```

## Metadata

Enable `metadata` to access `mrcpv2::REGISTRIES` and the crate's `GROUPS`.
