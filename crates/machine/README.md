# iana-machine

Type-safe, allocation-free Rust bindings for IANA `machine` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-machine = "0.1.0"
```

```rust
use iana_machine::machine_names::MachineNames;

assert_eq!(MachineNames::AMIGA_500.as_str(), "AMIGA-500");
```

## Metadata

Enable `metadata` to access `machine_names::REGISTRIES` and the crate's `GROUPS`.
