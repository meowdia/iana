# iana-dhcpv6-parameters

Type-safe, allocation-free Rust bindings for IANA `dhcpv6-parameters` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-dhcpv6-parameters = "0.1.0"
```

```rust
use iana_dhcpv6_parameters::dhcpv6::MessageTypes;

assert_eq!(MessageTypes::SOLICIT.value(), 1);
```

## Metadata

Enable `metadata` to access `dhcpv6::REGISTRIES` and the crate's `GROUPS`.
