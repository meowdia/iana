# iana-edhoc

Type-safe, allocation-free Rust bindings for IANA `edhoc` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-edhoc = "0.1.0"
```

```rust
use iana_edhoc::edhoc::EdhocExporterLabels;

assert_eq!(EdhocExporterLabels::DERIVED_OSCORE_MASTER_SECRET.value(), 0);
```

## Metadata

Enable `metadata` to access `edhoc::REGISTRIES` and the crate's `GROUPS`.
