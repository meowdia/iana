# iana-text

Type-safe, allocation-free Rust bindings for IANA `text` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-text = "0.1.0"
```

```rust
use iana_text::text_directory_registrations;

assert_eq!(text_directory_registrations::ID, "text-directory-registrations");
```

## Metadata

Enable `metadata` to access `text_directory_registrations::REGISTRIES` and the crate's `GROUPS`.
