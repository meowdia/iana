# iana-card-parameters

Type-safe, allocation-free Rust bindings for IANA `card-parameters` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-card-parameters = "0.1.0"
```

```rust
use iana_card_parameters::card::Layer2AccessTechnologyIdentifierRegistry;

assert_eq!(Layer2AccessTechnologyIdentifierRegistry::V0X00.value(), 0);
```

## Metadata

Enable `metadata` to access `card::REGISTRIES` and the crate's `GROUPS`.
