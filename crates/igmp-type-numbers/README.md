# iana-igmp-type-numbers

Type-safe, allocation-free Rust bindings for IANA `igmp-type-numbers` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-igmp-type-numbers = "0.1.0"
```

```rust
use iana_igmp_type_numbers::igmp_type_numbers::IgmpTypeNumbers;

assert_eq!(IgmpTypeNumbers::IGMP_MEMBERSHIP_QUERY.value(), 17);
```
