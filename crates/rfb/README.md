# iana-rfb

Type-safe, allocation-free Rust bindings for IANA `rfb` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-rfb = "0.1.0"
```

```rust
use iana_rfb::rfb::RemoteFramebufferSecurityTypes;

assert_eq!(RemoteFramebufferSecurityTypes::INVALID.as_str(), "Invalid");
```

## Metadata

Enable `metadata` to access `rfb::REGISTRIES` and the crate's `GROUPS`.
