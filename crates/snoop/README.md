# iana-snoop

Type-safe, allocation-free Rust bindings for IANA `snoop` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-snoop = "0.1.0"
```

```rust
use iana_snoop::snoop_datalink_types::DatalinkTypes;

assert_eq!(DatalinkTypes::IEEE_802_3.value(), 0);
```

## Metadata

Enable `metadata` to access `snoop_datalink_types::REGISTRIES` and the crate's `GROUPS`.
