# iana-internet

Type-safe, allocation-free Rust bindings for IANA `internet` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-internet = "0.1.0"
```

```rust
use iana_internet::internet_date_time_format;

assert_eq!(internet_date_time_format::ID, "internet-date-time-format");
```

## Metadata

Enable `metadata` to access `internet_date_time_format::REGISTRIES` and the crate's `GROUPS`.
