# iana-rtspv2-parameters

Type-safe, allocation-free Rust bindings for IANA `rtspv2-parameters` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-rtspv2-parameters = "0.1.0"
```

```rust
use iana_rtspv2_parameters::rtspv2::FeatureTags;

assert_eq!(FeatureTags::PLAY_BASIC.as_str(), "play.basic");
```

## Metadata

Enable `metadata` to access `rtspv2::REGISTRIES` and the crate's `GROUPS`.
