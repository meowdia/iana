# iana-pnfs

Type-safe, allocation-free Rust bindings for IANA `pnfs` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-pnfs = "0.1.0"
```

```rust
use iana_pnfs::pnfs_layout_types::PnfsLayoutTypes;

assert_eq!(PnfsLayoutTypes::LAYOUT4_NFSV4_1_FILES.value(), 1);
```

## Metadata

Enable `metadata` to access `pnfs_layout_types::REGISTRIES` and the crate's `GROUPS`.
