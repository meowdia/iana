# iana-power

Type-safe, allocation-free Rust bindings for IANA `power` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-power = "0.1.0"
```

```rust
use iana_power::power_state_sets::Ieee1621PowerStateSet;

assert_eq!(Ieee1621PowerStateSet::OFF.value(), 0);
```

## Metadata

Enable `metadata` to access `power_state_sets::REGISTRIES` and the crate's `GROUPS`.
