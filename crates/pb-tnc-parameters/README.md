# iana-pb-tnc-parameters

Type-safe, allocation-free Rust bindings for IANA `pb-tnc-parameters` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-pb-tnc-parameters = "0.1.0"
```

```rust
use iana_pb_tnc_parameters::pb_tnc::PbTncMessageTypes;

assert_eq!(PbTncMessageTypes::PB_EXPERIMENTAL.as_str(), "PB-Experimental");
```
