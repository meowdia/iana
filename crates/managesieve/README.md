# iana-managesieve

Type-safe, allocation-free Rust bindings for IANA `managesieve` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-managesieve = "0.1.0"
```

```rust
use iana_managesieve::managesieve::ManagesieveCapabilities;

assert_eq!(ManagesieveCapabilities::IMPLEMENTATION.as_str(), "IMPLEMENTATION");
```

## Metadata

Enable `metadata` to access `managesieve::REGISTRIES` and the crate's `GROUPS`.
