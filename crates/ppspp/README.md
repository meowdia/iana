# iana-ppspp

Type-safe, allocation-free Rust bindings for IANA `ppspp` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-ppspp = "0.1.0"
```

```rust
use iana_ppspp::ppspp::PpspPeerProtocolMessageTypeRegistry;

assert_eq!(PpspPeerProtocolMessageTypeRegistry::HANDSHAKE.value(), 0);
```

## Metadata

Enable `metadata` to access `ppspp::REGISTRIES` and the crate's `GROUPS`.
