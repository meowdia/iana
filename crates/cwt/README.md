# iana-cwt

Type-safe, allocation-free Rust bindings for IANA `cwt` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-cwt = "0.1.0"
```

```rust
use iana_cwt::cwt::CwtStatusMechanisms;

assert_eq!(CwtStatusMechanisms::STATUS_LIST.as_str(), "status_list");
```

## Metadata

Enable `metadata` to access `cwt::REGISTRIES` and the crate's `GROUPS`.
