# iana-esp

Type-safe, allocation-free Rust bindings for IANA `esp` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-esp = "0.1.0"
```

```rust
use iana_esp::esp_aggfrag_payload::AggfragPayloadSubTypes;

assert_eq!(AggfragPayloadSubTypes::NON_CONGESTION_CONTROL_FORMAT.value(), 0);
```

## Metadata

Enable `metadata` to access `esp_aggfrag_payload::REGISTRIES` and the crate's `GROUPS`.
