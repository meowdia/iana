# iana-protocol

Type-safe, allocation-free Rust bindings for IANA `protocol` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-protocol = "0.1.0"
```

```rust
use iana_protocol::protocol_numbers::AssignedInternetProtocolNumbers;

assert_eq!(AssignedInternetProtocolNumbers::IPV6_HOP_BY_HOP_OPTION.value(), 0);
```

## Metadata

Enable `metadata` to access `protocol_numbers::REGISTRIES` and the crate's `GROUPS`.
