# iana-ice

Type-safe, allocation-free Rust bindings for IANA `ice` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-ice = "0.1.0"
```

```rust
use iana_ice::ice::IceOptions;

assert_eq!(IceOptions::RTP_ECN.as_str(), "rtp+ecn");
```

## Metadata

Enable `metadata` to access `ice::REGISTRIES` and the crate's `GROUPS`.
