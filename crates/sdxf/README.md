# iana-sdxf

Type-safe, allocation-free Rust bindings for IANA `sdxf` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-sdxf = "0.1.0"
```

```rust
use iana_sdxf::sdxf::CompressionMethodsForSdxf;

assert_eq!(CompressionMethodsForSdxf::RUN_LENGTH_ALGORITHM.value(), 1);
```

## Metadata

Enable `metadata` to access `sdxf::REGISTRIES` and the crate's `GROUPS`.
