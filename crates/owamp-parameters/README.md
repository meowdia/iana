# iana-owamp-parameters

Type-safe, allocation-free Rust bindings for IANA `owamp-parameters` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-owamp-parameters = "0.1.0"
```

```rust
use iana_owamp_parameters::owamp::OwampControlCommandNumbers;

assert_eq!(OwampControlCommandNumbers::REQUEST_SESSION.value(), 1);
```

## Metadata

Enable `metadata` to access `owamp::REGISTRIES` and the crate's `GROUPS`.
