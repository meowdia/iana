# iana-rpki

Type-safe, allocation-free Rust bindings for IANA `rpki` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-rpki = "0.1.0"
```

```rust
use iana_rpki::rpki::RpkiSignedObjects;

assert_eq!(RpkiSignedObjects::ROUTE_ORIGINATION_AUTHORIZATION.as_str(), "Route Origination Authorization");
```

## Metadata

Enable `metadata` to access `rpki::REGISTRIES` and the crate's `GROUPS`.
