# iana-bootp-dhcp-parameters

Type-safe, allocation-free Rust bindings for IANA `bootp-dhcp-parameters` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-bootp-dhcp-parameters = "0.1.0"
```

```rust
use iana_bootp_dhcp_parameters::bootp_dhcp::BootpVendorExtensionsAndDhcpOptions;

assert_eq!(BootpVendorExtensionsAndDhcpOptions::NONE.value(), 0);
```

## Metadata

Enable `metadata` to access `bootp_dhcp::REGISTRIES` and the crate's `GROUPS`.
