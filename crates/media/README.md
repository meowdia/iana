# iana-media

Type-safe, allocation-free Rust bindings for IANA `media` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-media = { version = "0.1.0", features = ["media-control-channel"] }
```

```rust
use iana_media::media_control_channel::ControlPackages;

assert_eq!(ControlPackages::MSC_MIXER_1_0.as_str(), "msc-mixer/1.0");
```
