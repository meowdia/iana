# iana-tsig

Type-safe, allocation-free Rust bindings for IANA `tsig` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-tsig = "0.1.0"
```

```rust
use iana_tsig::tsig_algorithm_names::TsigAlgorithmNames;

assert_eq!(TsigAlgorithmNames::GSS_TSIG.as_str(), "gss-tsig");
```

## Metadata

Enable `metadata` to access `tsig_algorithm_names::REGISTRIES` and the crate's `GROUPS`.
