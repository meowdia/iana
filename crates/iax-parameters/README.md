# iana-iax-parameters

Type-safe, allocation-free Rust bindings for IANA `iax-parameters` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-iax-parameters = "0.1.0"
```

```rust
use iana_iax_parameters::iax::IaxMetaCommands;

assert_eq!(IaxMetaCommands::INDICATES_THAT_FRAME_IS_A_TRUNK_META_FRAME.value(), 1);
```

## Metadata

Enable `metadata` to access `iax::REGISTRIES` and the crate's `GROUPS`.
