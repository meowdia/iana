# iana-isakmp-registry

Type-safe, allocation-free Rust bindings for IANA `isakmp-registry` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-isakmp-registry = "0.1.0"
```

```rust
use iana_isakmp_registry::isakmp_registry::IpsecSituationDefinition;

assert_eq!(IpsecSituationDefinition::SIT_IDENTITY_ONLY.value(), 1);
```

## Metadata

Enable `metadata` to access `isakmp_registry::REGISTRIES` and the crate's `GROUPS`.
