# iana-urlauth

Type-safe, allocation-free Rust bindings for IANA `urlauth` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-urlauth = { version = "0.1.0", features = ["urlauth-access-ids"] }
```

```rust
use iana_urlauth::urlauth_access_ids;

assert_eq!(urlauth_access_ids::ID, "urlauth-access-ids");
```

## Features

No catalogs are enabled by default. Add `metadata` alongside catalog features
to access their `REGISTRIES` and the crate's `GROUPS`.
