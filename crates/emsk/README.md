# iana-emsk

Type-safe, allocation-free Rust bindings for IANA `emsk` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-emsk = "0.1.0"
```

```rust
use iana_emsk::emsk::EmskPrfNumbers;

assert_eq!(EmskPrfNumbers::HMAC_SHA_256_PRF_DEFAULT.value(), 1);
```

## Metadata

Enable `metadata` to access `emsk::REGISTRIES` and the crate's `GROUPS`.
