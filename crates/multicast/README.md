# iana-multicast

Type-safe, allocation-free Rust bindings for IANA `multicast` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-multicast = { version = "0.1.0", features = ["multicast-acquisition"] }
```

```rust
use iana_multicast::multicast_acquisition::MulticastAcquisitionMethodRegistry;

assert_eq!(MulticastAcquisitionMethodRegistry::SIMPLE_JOIN_NO_EXPLICIT_METHOD.value(), 1);
```

## Features

No catalogs are enabled by default. Add `metadata` alongside catalog features
to access their `REGISTRIES` and the crate's `GROUPS`.
