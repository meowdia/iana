# iana-core-parameters

Type-safe, allocation-free Rust bindings for IANA `core-parameters` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-core-parameters = "0.1.0"
```

```rust
use iana_core_parameters::core::ResourceTypeRtLinkTargetAttributeValues;

assert_eq!(ResourceTypeRtLinkTargetAttributeValues::CORE_GP.as_str(), "core.gp");
```

## Metadata

Enable `metadata` to access `core::REGISTRIES` and the crate's `GROUPS`.
