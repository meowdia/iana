# iana-ospf

Type-safe, allocation-free Rust bindings for IANA `ospf` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-ospf = { version = "0.1.0", features = ["ospf-parameters"] }
```

```rust
use iana_ospf::ospf::OspfRouterInformationRiTlvs;

assert_eq!(OspfRouterInformationRiTlvs::ROUTER_INFORMATIONAL_CAPABILITIES.value(), 1);
```
