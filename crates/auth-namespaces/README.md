# iana-auth-namespaces

Type-safe, allocation-free Rust bindings for IANA `auth-namespaces` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-auth-namespaces = "0.1.0"
```

```rust
use iana_auth_namespaces::auth_namespaces::ProtocolNameSpaceValues;

assert_eq!(ProtocolNameSpaceValues::CONFIGURATION_TOKEN.value(), 0);
```

## Metadata

Enable `metadata` to access `auth_namespaces::REGISTRIES` and the crate's `GROUPS`.
