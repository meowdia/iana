# iana-arp

Type-safe, allocation-free Rust bindings for IANA `arp` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-arp = "0.1.0"
```

```rust
use iana_arp::arp::OperationCodes;

assert_eq!(OperationCodes::V0.value(), 0);
```

## Metadata

Enable `metadata` to access `arp::REGISTRIES` and the crate's `GROUPS`.
