# iana-segment

Type-safe, allocation-free Rust bindings for IANA `segment` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-segment = "0.1.0"
```

```rust
use iana_segment::segment_routing::Srv6EndpointBehaviors;

assert_eq!(Srv6EndpointBehaviors::END.value(), 1);
```
