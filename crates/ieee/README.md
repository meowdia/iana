# iana-ieee

Type-safe, allocation-free Rust bindings for IANA `ieee` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-ieee = "0.1.0"
```

```rust
use iana_ieee::ieee_802_numbers;

assert_eq!(ieee_802_numbers::ID, "ieee-802-numbers");
```

## Metadata

Enable `metadata` to access `ieee_802_numbers::REGISTRIES` and the crate's `GROUPS`.
