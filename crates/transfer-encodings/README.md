# iana-transfer-encodings

Type-safe, allocation-free Rust bindings for IANA `transfer-encodings` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-transfer-encodings = "0.1.0"
```

```rust
use iana_transfer_encodings::transfer_encodings::TransferEncodings;

assert_eq!(TransferEncodings::V7BIT.as_str(), "7bit");
```

## Metadata

Enable `metadata` to access `transfer_encodings::REGISTRIES` and the crate's `GROUPS`.
