# iana-sec

Type-safe, allocation-free Rust bindings for IANA `sec` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-sec = "0.1.0"
```

```rust
use iana_sec::sec_ext_enum::SecurityExternalEnumerationRegistry;

assert_eq!(SecurityExternalEnumerationRegistry::COMMON_VULNERABILITIES_AND_EXPOSURES.as_str(), "Common Vulnerabilities and Exposures");
```

## Metadata

Enable `metadata` to access `sec_ext_enum::REGISTRIES` and the crate's `GROUPS`.
