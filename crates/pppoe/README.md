# iana-pppoe

Type-safe, allocation-free Rust bindings for IANA `pppoe` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-pppoe = "0.1.0"
```

```rust
use iana_pppoe::pppoe::PppoeActiveDiscoveryCodeFields8BitValues;

assert_eq!(PppoeActiveDiscoveryCodeFields8BitValues::PPP_SESSION_STAGE.as_str(), "PPP Session Stage");
```

## Metadata

Enable `metadata` to access `pppoe::REGISTRIES` and the crate's `GROUPS`.
