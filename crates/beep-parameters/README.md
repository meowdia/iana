# iana-beep-parameters

Type-safe, allocation-free Rust bindings for IANA `beep-parameters` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-beep-parameters = "0.1.0"
```

```rust
use iana_beep_parameters::beep;

assert_eq!(beep::ID, "beep-parameters");
```
