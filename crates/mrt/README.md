# iana-mrt

Type-safe, allocation-free Rust bindings for IANA `mrt` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-mrt = { version = "0.1.0", features = ["mrt"] }
```

```rust
use iana_mrt::mrt::TypeCodes;

assert_eq!(TypeCodes::NULL_DEPRECATED.value(), 0);
```

## Features

No catalogs are enabled by default. Add `metadata` alongside catalog features
to access their `REGISTRIES` and the crate's `GROUPS`.

| Feature | Module |
|---|---|
| [`mrt`](https://www.iana.org/assignments/mrt/) | `mrt` |
| [`mrt-parameters`](https://www.iana.org/assignments/mrt-parameters/) | `mrt_parameters` |
