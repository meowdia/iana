# iana-language

Type-safe, allocation-free Rust bindings for IANA `language` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-language = { version = "0.1.0", features = ["language-subtag-registry"] }
```

```rust
use iana_language::language_subtag_registry;

assert_eq!(language_subtag_registry::ID, "language-subtag-registry");
```

## Features

No catalogs are enabled by default. Add `metadata` alongside catalog features
to access their `REGISTRIES` and the crate's `GROUPS`.

| Feature | Module |
|---|---|
| [`language-subtag-registry`](https://www.iana.org/assignments/language-subtag-registry/) | `language_subtag_registry` |
| [`language-subtags-tags-extensions`](https://www.iana.org/assignments/language-subtags-tags-extensions/) | `language_subtags_tags_extensions` |
