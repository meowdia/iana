# iana-cose

Type-safe, allocation-free Rust bindings for IANA `cose` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-cose = { version = "0.1.0", features = ["cose"] }
```

```rust
use iana_cose::cose::CoseKeyCommonParameters;

assert_eq!(CoseKeyCommonParameters::RESERVED_FOR_PRIVATE_USE.as_str(), "Reserved for Private Use");
```
