# iana-quic

Type-safe, allocation-free Rust bindings for IANA `quic` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-quic = "0.2.0"
```

```rust
use iana_quic::quic::QuicVersions;

assert_eq!(QuicVersions::V0X00000000.value(), 0);
```

## Metadata

Enable `metadata` to access `quic::REGISTRIES` and the crate's `GROUPS`.
