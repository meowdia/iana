# iana-reload

Type-safe, allocation-free Rust bindings for IANA `reload` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-reload = "0.1.0"
```

```rust
use iana_reload::reload::ReloadApplicationId;

assert_eq!(ReloadApplicationId::INVALID.value(), 0);
```

## Metadata

Enable `metadata` to access `reload::REGISTRIES` and the crate's `GROUPS`.
