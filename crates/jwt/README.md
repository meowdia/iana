# iana-jwt

Type-safe, allocation-free Rust bindings for IANA `jwt` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-jwt = "0.1.0"
```

```rust
use iana_jwt::jwt::JsonWebTokenClaims;

assert_eq!(JsonWebTokenClaims::ISS.as_str(), "iss");
```

## Metadata

Enable `metadata` to access `jwt::REGISTRIES` and the crate's `GROUPS`.
