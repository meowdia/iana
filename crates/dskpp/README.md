# iana-dskpp

Type-safe, allocation-free Rust bindings for IANA `dskpp` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-dskpp = "0.1.0"
```

```rust
use iana_dskpp::dskpp::StatusCodes;

assert_eq!(StatusCodes::CONTINUE.as_str(), "Continue");
```

## Metadata

Enable `metadata` to access `dskpp::REGISTRIES` and the crate's `GROUPS`.
