# iana-mikey

Type-safe, allocation-free Rust bindings for IANA `mikey` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-mikey = "0.1.0"
```

```rust
use iana_mikey::mikey_payloads::CommonHeaderPayloadFieldNames;

assert_eq!(CommonHeaderPayloadFieldNames::VERSION.as_str(), "version");
```

## Metadata

Enable `metadata` to access `mikey_payloads::REGISTRIES` and the crate's `GROUPS`.
