# iana-webpush-parameters

Type-safe, allocation-free Rust bindings for IANA `webpush-parameters` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-webpush-parameters = "0.1.0"
```

```rust
use iana_webpush_parameters::webpush::WebPushIdentifiers;

assert_eq!(WebPushIdentifiers::URN_IETF_PARAMS_PUSH.as_str(), "urn:ietf:params:push");
```

## Metadata

Enable `metadata` to access `webpush::REGISTRIES` and the crate's `GROUPS`.
