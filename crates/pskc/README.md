# iana-pskc

Type-safe, allocation-free Rust bindings for IANA `pskc` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-pskc = "0.1.0"
```

```rust
use iana_pskc::pskc::AlgorithmUriRegistryAndRelatedPskcProfiles;

assert_eq!(AlgorithmUriRegistryAndRelatedPskcProfiles::HOTP.as_str(), "HOTP");
```

## Metadata

Enable `metadata` to access `pskc::REGISTRIES` and the crate's `GROUPS`.
