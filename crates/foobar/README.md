# iana-foobar

Type-safe, allocation-free Rust bindings for IANA `foobar` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-foobar = "0.1.0"
```

```rust
use iana_foobar::foobar_af_numbers::AssignedFoobarAddressFamilies;

assert_eq!(AssignedFoobarAddressFamilies::V16.value(), 16);
```

## Metadata

Enable `metadata` to access `foobar_af_numbers::REGISTRIES` and the crate's `GROUPS`.
