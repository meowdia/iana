# iana-location

Type-safe, allocation-free Rust bindings for IANA `location` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-location = "0.1.0"
```

```rust
use iana_location::location_type_registry::LocationTypes;

assert_eq!(LocationTypes::AIRCRAFT.as_str(), "aircraft");
```

## Metadata

Enable `metadata` to access `location_type_registry::REGISTRIES` and the crate's `GROUPS`.
