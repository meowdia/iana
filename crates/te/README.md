# iana-te

Type-safe, allocation-free Rust bindings for IANA `te` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-te = { version = "0.1.0", features = ["te-link-capabilities"] }
```

```rust
use iana_te::te_link_capabilities::TeNodeCapabilities;

assert_eq!(TeNodeCapabilities::B_BIT_P2MP_BRANCH_LSR_CAPABILITY.value(), 0);
```

## Features

No catalogs are enabled by default. Add `metadata` alongside catalog features
to access their `REGISTRIES` and the crate's `GROUPS`.

| Feature | Module |
|---|---|
| [`te-link-capabilities`](https://www.iana.org/assignments/te-link-capabilities/) | `te_link_capabilities` |
| [`te-types`](https://www.iana.org/assignments/te-types/) | `te_types` |
