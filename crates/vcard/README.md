# iana-vcard

Type-safe, allocation-free Rust bindings for IANA `vcard` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-vcard = "0.1.0"
```

```rust
use iana_vcard::vcard_elements::VcardValueDataTypes;

assert_eq!(VcardValueDataTypes::BOOLEAN.as_str(), "BOOLEAN");
```

## Metadata

Enable `metadata` to access `vcard_elements::REGISTRIES` and the crate's `GROUPS`.
