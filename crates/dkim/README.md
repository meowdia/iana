# iana-dkim

Type-safe, allocation-free Rust bindings for IANA `dkim` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-dkim = "0.1.0"
```

```rust
use iana_dkim::dkim;

assert_eq!(dkim::ID, "dkim-parameters");
```

## Metadata

Enable `metadata` to access `dkim::REGISTRIES` and the crate's `GROUPS`.
