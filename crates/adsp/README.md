# iana-adsp

Type-safe, allocation-free Rust bindings for IANA `adsp` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-adsp = "0.1.0"
```

```rust
use iana_adsp::adsp::AdspSpecificationTags;

assert_eq!(AdspSpecificationTags::DKIM.as_str(), "dkim");
```

## Metadata

Enable `metadata` to access `adsp::REGISTRIES` and the crate's `GROUPS`.
