# iana-xml

Type-safe, allocation-free Rust bindings for IANA `xml` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-xml = { version = "0.1.0", features = ["xml-ns-provided-by"] }
```

```rust
use iana_xml::xml_ns_provided_by::XmlNamespacesForProvidedByElementsForUseWithPidfLoObjects;

assert_eq!(XmlNamespacesForProvidedByElementsForUseWithPidfLoObjects::URN_IETF_PARAMS_XML_NS_EMERGENCYCALLDATA.as_str(), "urn:ietf:params:xml:ns:EmergencyCallData");
```
