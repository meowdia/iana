# iana-icmp

Type-safe, allocation-free Rust bindings for IANA `icmp` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-icmp = "0.1.0"
```

```rust
use iana_icmp::icmp::IcmpTypeNumbers;

assert_eq!(IcmpTypeNumbers::ECHO_REPLY.value(), 0);
```

## Metadata

Enable `metadata` to access `icmp::REGISTRIES` and the crate's `GROUPS`.
