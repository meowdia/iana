# iana-sip

Type-safe, allocation-free Rust bindings for IANA `sip` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-sip = { version = "0.1.0", features = ["sip-parameters"] }
```

```rust
use iana_sip::sip::HeaderFields;

assert_eq!(HeaderFields::ACCEPT.as_str(), "Accept");
```
