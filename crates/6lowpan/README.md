# iana-6lowpan

Type-safe, allocation-free Rust bindings for IANA `6lowpan` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-6lowpan = "0.1.0"
```

```rust
use iana_6lowpan::v6lowpan::DispatchTypeField;

assert_eq!(DispatchTypeField::V00_XXXXXX.as_str(), "00 xxxxxx");
```

## Metadata

Enable `metadata` to access `v6lowpan::REGISTRIES` and the crate's `GROUPS`.
