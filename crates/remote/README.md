# iana-remote

Type-safe, allocation-free Rust bindings for IANA `remote` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-remote = "0.1.0"
```

```rust
use iana_remote::remote_direct_data_placement::RdmaCmPrivateDataIdentifiers;

assert_eq!(RdmaCmPrivateDataIdentifiers::RPC_OVER_RDMA_VERSION_1_CM_PRIVATE_DATA.value(), 4138405400);
```

## Metadata

Enable `metadata` to access `remote_direct_data_placement::REGISTRIES` and the crate's `GROUPS`.
