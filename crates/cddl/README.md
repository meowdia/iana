# iana-cddl

Type-safe, allocation-free Rust bindings for IANA `cddl` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-cddl = "0.1.0"
```

```rust
use iana_cddl::cddl::CddlControlOperators;

assert_eq!(CddlControlOperators::SIZE.as_str(), ".size");
```

## Metadata

Enable `metadata` to access `cddl::REGISTRIES` and the crate's `GROUPS`.
