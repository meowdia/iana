# iana-device-identification

Type-safe, allocation-free Rust bindings for IANA `device-identification` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-device-identification = "0.1.0"
```

```rust
use iana_device_identification::device_identification::DevUrnSubtypes;

assert_eq!(DevUrnSubtypes::MAC.as_str(), "mac");
```

## Metadata

Enable `metadata` to access `device_identification::REGISTRIES` and the crate's `GROUPS`.
