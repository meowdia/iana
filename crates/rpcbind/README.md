# iana-rpcbind

Type-safe, allocation-free Rust bindings for IANA `rpcbind` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-rpcbind = "0.1.0"
```

```rust
use iana_rpcbind::rpcbind_transport::TransportSemanticsRNcSemantics;

assert_eq!(TransportSemanticsRNcSemantics::CONNECTIONLESS.value(), 1);
```

## Metadata

Enable `metadata` to access `rpcbind_transport::REGISTRIES` and the crate's `GROUPS`.
