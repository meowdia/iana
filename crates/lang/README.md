# iana-lang

Type-safe, allocation-free Rust bindings for IANA `lang` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-lang = { version = "0.1.0", features = ["lang-subtags-templates"] }
```

```rust
use iana_lang::lang_subtags_templates;

assert_eq!(lang_subtags_templates::ID, "lang-subtags-templates");
```

## Features

No catalogs are enabled by default. Add `metadata` alongside catalog features
to access their `REGISTRIES` and the crate's `GROUPS`.

| Feature | Module |
|---|---|
| [`lang-subtags-templates`](https://www.iana.org/assignments/lang-subtags-templates/) | `lang_subtags_templates` |
| [`lang-tag-apps`](https://www.iana.org/assignments/lang-tag-apps/) | `lang_tag_apps` |
