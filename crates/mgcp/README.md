# iana-mgcp

Type-safe, allocation-free Rust bindings for IANA `mgcp` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-mgcp = { version = "0.1.0", features = ["mgcp-localconnectionoptions"] }
```

```rust
use iana_mgcp::mgcp_localconnectionoptions::LocalconnectionoptionsSubRegistry;

assert_eq!(LocalconnectionoptionsSubRegistry::B.as_str(), "b");
```

## Features

No catalogs are enabled by default. Add `metadata` alongside catalog features
to access their `REGISTRIES` and the crate's `GROUPS`.

| Feature | Module |
|---|---|
| [`mgcp-localconnectionoptions`](https://www.iana.org/assignments/mgcp-localconnectionoptions/) | `mgcp_localconnectionoptions` |
| [`mgcp-packages`](https://www.iana.org/assignments/mgcp-packages/) | `mgcp_packages` |
