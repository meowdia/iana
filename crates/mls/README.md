# iana-mls

Type-safe, allocation-free Rust bindings for IANA `mls` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-mls = "0.1.0"
```

```rust
use iana_mls::mls::MlsCipherSuites;

assert_eq!(MlsCipherSuites::MLS_128_DHKEMX25519_AES128GCM_SHA256_ED25519.value(), 1);
```

## Metadata

Enable `metadata` to access `mls::REGISTRIES` and the crate's `GROUPS`.
