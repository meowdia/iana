# iana-ipseckey

Type-safe, allocation-free Rust bindings for IANA `ipseckey` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-ipseckey = "0.1.0"
```

```rust
use iana_ipseckey::ipseckey_rr::AlgorithmTypeField;

assert_eq!(AlgorithmTypeField::NO_PUBLIC_KEY_IS_PRESENT.value(), 0);
```

## Metadata

Enable `metadata` to access `ipseckey_rr::REGISTRIES` and the crate's `GROUPS`.
