# iana-ospfv3

Type-safe, allocation-free Rust bindings for IANA `ospfv3` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-ospfv3 = { version = "0.1.0", features = ["ospfv3-parameters"] }
```

```rust
use iana_ospfv3::ospfv3::Ospfv3Options24Bits;

assert_eq!(Ospfv3Options24Bits::V6_BIT.value(), 1);
```

## Features

No catalogs are enabled by default. Add `metadata` alongside catalog features
to access their `REGISTRIES` and the crate's `GROUPS`.

| Feature | Module |
|---|---|
| [`ospfv3-authentication-trailer-options`](https://www.iana.org/assignments/ospfv3-authentication-trailer-options/) | `ospfv3_authentication_trailer_options` |
| [`ospfv3-parameters`](https://www.iana.org/assignments/ospfv3-parameters/) | `ospfv3` |
