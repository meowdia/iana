# iana-ipv4

Type-safe, allocation-free Rust bindings for IANA `ipv4` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-ipv4 = { version = "0.1.0", features = ["ipv4-address-space"] }
```

```rust
use iana_ipv4::ipv4_address_space;

assert_eq!(ipv4_address_space::ID, "ipv4-address-space");
```

## Features

No catalogs are enabled by default. Add `metadata` alongside catalog features
to access their `REGISTRIES` and the crate's `GROUPS`.

| Feature | Module |
|---|---|
| [`ipv4-address-space`](https://www.iana.org/assignments/ipv4-address-space/) | `ipv4_address_space` |
| [`ipv4-recovered-address-space`](https://www.iana.org/assignments/ipv4-recovered-address-space/) | `ipv4_recovered_address_space` |
