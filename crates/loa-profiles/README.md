# iana-loa-profiles

Type-safe, allocation-free Rust bindings for IANA `loa-profiles` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-loa-profiles = "0.1.0"
```

```rust
use iana_loa_profiles::loa_profiles::LevelOfAssuranceProfiles;

assert_eq!(LevelOfAssuranceProfiles::SAMBI_SE_LOA2.as_str(), "sambi.se-loa2");
```

## Metadata

Enable `metadata` to access `loa_profiles::REGISTRIES` and the crate's `GROUPS`.
