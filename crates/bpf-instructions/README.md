# iana-bpf-instructions

Type-safe, allocation-free Rust bindings for IANA `bpf-instructions` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-bpf-instructions = "0.1.0"
```

```rust
use iana_bpf_instructions::bpf_instructions::BpfInstructionConformanceGroups;

assert_eq!(BpfInstructionConformanceGroups::ATOMIC32.as_str(), "atomic32");
```

## Metadata

Enable `metadata` to access `bpf_instructions::REGISTRIES` and the crate's `GROUPS`.
