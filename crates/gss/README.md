# iana-gss

Type-safe, allocation-free Rust bindings for IANA `gss` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-gss = { version = "0.1.0", features = ["gss-api-parameters"] }
```

```rust
use iana_gss::gss_api::GssApiUrnParameters;

assert_eq!(GssApiUrnParameters::RADIUS_ATTRIBUTE.as_str(), "radius-attribute");
```

## Features

No catalogs are enabled by default. Add `metadata` alongside catalog features
to access their `REGISTRIES` and the crate's `GROUPS`.

| Feature | Module |
|---|---|
| [`gss-api-parameters`](https://www.iana.org/assignments/gss-api-parameters/) | `gss_api` |
| [`gss-eap-parameters`](https://www.iana.org/assignments/gss-eap-parameters/) | `gss_eap` |
