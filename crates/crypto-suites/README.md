# iana-crypto-suites

Type-safe, allocation-free Rust bindings for IANA `crypto-suites` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-crypto-suites = "0.1.0"
```

```rust
use iana_crypto_suites::crypto_suites;

assert_eq!(crypto_suites::ID, "crypto-suites");
```
