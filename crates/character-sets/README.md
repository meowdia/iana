# iana-character-sets

Type-safe, allocation-free Rust bindings for IANA `character-sets` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-character-sets = "0.2.0"
```

```rust
use iana_character_sets::character_sets::CharacterSets;

assert_eq!(CharacterSets::ANSI_X3_4_1986.value(), 3);
```

## Metadata

Enable `metadata` to access `character_sets::REGISTRIES` and the crate's `GROUPS`.
