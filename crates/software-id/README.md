# iana-software-id

Type-safe, allocation-free Rust bindings for IANA `software-id` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-software-id = "0.1.0"
```

```rust
use iana_software_id::software_id::SoftwareIdVersionSchemeValues;

assert_eq!(SoftwareIdVersionSchemeValues::MULTIPARTNUMERIC.value(), 1);
```

## Metadata

Enable `metadata` to access `software_id::REGISTRIES` and the crate's `GROUPS`.
