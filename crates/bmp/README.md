# iana-bmp

Type-safe, allocation-free Rust bindings for IANA `bmp` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-bmp = "0.1.0"
```

```rust
use iana_bmp::bmp::BmpMessageTypes;

assert_eq!(BmpMessageTypes::ROUTE_MONITORING.value(), 0);
```

## Metadata

Enable `metadata` to access `bmp::REGISTRIES` and the crate's `GROUPS`.
