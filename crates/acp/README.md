# iana-acp

Type-safe, allocation-free Rust bindings for IANA `acp` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-acp = "0.1.0"
```

```rust
use iana_acp::acp::AcpAddressType;

assert_eq!(AcpAddressType::ACP_ZONE_ADDRESSING_SUB_SCHEME_ACP_MANUAL_ADDRESSING_SUB_SCHEME.value(), 0);
```

## Metadata

Enable `metadata` to access `acp::REGISTRIES` and the crate's `GROUPS`.
