# iana-svrloc

Type-safe, allocation-free Rust bindings for IANA `svrloc` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-svrloc = { version = "0.1.0", features = ["svrloc-cryptographic-bsd"] }
```

```rust
use iana_svrloc::svrloc_cryptographic_bsd;

assert_eq!(svrloc_cryptographic_bsd::ID, "svrloc-cryptographic-bsd");
```
