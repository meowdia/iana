# iana-pal

Type-safe, allocation-free Rust bindings for IANA `pal` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-pal = "0.1.0"
```

```rust
use iana_pal::pal_package_types::PalPackageTypes;

assert_eq!(PalPackageTypes::ADDITIONAL_PAL_VALUE_PRESENT.value(), 1);
```

## Metadata

Enable `metadata` to access `pal_package_types::REGISTRIES` and the crate's `GROUPS`.
