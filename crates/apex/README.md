# iana-apex

Type-safe, allocation-free Rust bindings for IANA `apex` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-apex = "0.1.0"
```

```rust
use iana_apex::apex;

assert_eq!(apex::ID, "apex");
```
