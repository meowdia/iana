# iana-dsr-parameters

Type-safe, allocation-free Rust bindings for IANA `dsr-parameters` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-dsr-parameters = "0.1.0"
```

```rust
use iana_dsr_parameters::dsr::DynamicSourceRoutingDsrProtocolOptions;

assert_eq!(DynamicSourceRoutingDsrProtocolOptions::PADN_OPTION.value(), 0);
```

## Metadata

Enable `metadata` to access `dsr::REGISTRIES` and the crate's `GROUPS`.
