# iana-http

Type-safe, allocation-free Rust bindings for IANA `http` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-http = { version = "0.1.0", features = ["http-parameters"] }
```

```rust
use iana_http::http::HttpContentCodingRegistry;

assert_eq!(HttpContentCodingRegistry::AES128GCM.as_str(), "aes128gcm");
```
