# iana-norm-parameters

Type-safe, allocation-free Rust bindings for IANA `norm-parameters` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-norm-parameters = "0.1.0"
```

```rust
use iana_norm_parameters::norm::NormHeaderExtensionTypes;

assert_eq!(NormHeaderExtensionTypes::EXT_AUTH.value(), 1);
```

Enable `metadata` to access `norm::REGISTRIES` and the crate's `GROUPS`.
