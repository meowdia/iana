# iana-iodef2

Type-safe, allocation-free Rust bindings for IANA `iodef2` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-iodef2 = "0.1.0"
```

```rust
use iana_iodef2::iodef2::Restriction;

assert_eq!(Restriction::PUBLIC.as_str(), "public");
```

## Metadata

Enable `metadata` to access `iodef2::REGISTRIES` and the crate's `GROUPS`.
