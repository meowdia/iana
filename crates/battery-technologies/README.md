# iana-battery-technologies

Type-safe, allocation-free Rust bindings for IANA `battery-technologies` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-battery-technologies = "0.1.0"
```

```rust
use iana_battery_technologies::battery_technologies::BatteryTechnologies;

assert_eq!(BatteryTechnologies::UNKNOWN.value(), 1);
```
