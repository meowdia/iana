# iana-sasl

Type-safe, allocation-free Rust bindings for IANA `sasl` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-sasl = "0.1.0"
```

```rust
use iana_sasl::sasl_mechanisms;

assert_eq!(sasl_mechanisms::ID, "sasl-mechanisms");
```

## Metadata

Enable `metadata` to access `sasl_mechanisms::REGISTRIES` and the crate's `GROUPS`.
