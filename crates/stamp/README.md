# iana-stamp

Type-safe, allocation-free Rust bindings for IANA `stamp` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-stamp = "0.1.0"
```

```rust
use iana_stamp::stamp_tlv_types::StampTlvTypes;

assert_eq!(StampTlvTypes::EXTRA_PADDING.value(), 1);
```

## Metadata

Enable `metadata` to access `stamp_tlv_types::REGISTRIES` and the crate's `GROUPS`.
