# iana-sigcomp

Type-safe, allocation-free Rust bindings for IANA `sigcomp` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-sigcomp = "0.1.0"
```

```rust
use iana_sigcomp::sigcomp_namespace;

assert_eq!(sigcomp_namespace::ID, "sigcomp-namespace");
```

## Metadata

Enable `metadata` to access `sigcomp_namespace::REGISTRIES` and the crate's `GROUPS`.
