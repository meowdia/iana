# iana-aodv

Type-safe, allocation-free Rust bindings for IANA `aodv` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-aodv = "0.1.0"
```

```rust
use iana_aodv::aodv::AodvMessageTypesForMessagesSentToPort654;

assert_eq!(AodvMessageTypesForMessagesSentToPort654::V1.value(), 1);
```

## Metadata

Enable `metadata` to access `aodv::REGISTRIES` and the crate's `GROUPS`.
