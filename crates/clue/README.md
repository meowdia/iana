# iana-clue

Type-safe, allocation-free Rust bindings for IANA `clue` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-clue = "0.1.0"
```

```rust
use iana_clue::clue::ClueSchemaView;

assert_eq!(ClueSchemaView::ROOM.as_str(), "room");
```

Enable `metadata` to access `clue::REGISTRIES` and the crate's `GROUPS`.
