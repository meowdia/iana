# iana-urn

Type-safe, allocation-free Rust bindings for IANA `urn` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-urn = { version = "0.1.0", features = ["urn-namespaces"] }
```

```rust
use iana_urn::urn_namespaces::FormalUrnNamespaces;

assert_eq!(FormalUrnNamespaces::V3GPP.as_str(), "3gpp");
```

## Features

No catalogs are enabled by default. Add `metadata` alongside catalog features
to access their `REGISTRIES` and the crate's `GROUPS`.

| Feature | Module |
|---|---|
| [`urn-namespaces`](https://www.iana.org/assignments/urn-namespaces/) | `urn_namespaces` |
| [`urn-serviceid-labels`](https://www.iana.org/assignments/urn-serviceid-labels/) | `urn_serviceid_labels` |
