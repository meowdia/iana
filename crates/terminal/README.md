# iana-terminal

Type-safe, allocation-free Rust bindings for IANA `terminal` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-terminal = "0.1.0"
```

```rust
use iana_terminal::terminal_type_names::TerminalTypeNames;

assert_eq!(TerminalTypeNames::ADDS_CONSUL_980.as_str(), "ADDS-CONSUL-980");
```

## Metadata

Enable `metadata` to access `terminal_type_names::REGISTRIES` and the crate's `GROUPS`.
