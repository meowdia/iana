# iana-nhrp-types

Type-safe, allocation-free Rust bindings for IANA `nhrp-types` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-nhrp-types = "0.1.0"
```

```rust
use iana_nhrp_types::nhrp_types::NhrpPacketTypes;

assert_eq!(NhrpPacketTypes::NHRP_RESOLUTION_REQUEST.value(), 1);
```

## Metadata

Enable `metadata` to access `nhrp_types::REGISTRIES` and the crate's `GROUPS`.
