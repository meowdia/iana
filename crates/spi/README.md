# iana-spi

Type-safe, allocation-free Rust bindings for IANA `spi` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-spi = "0.1.0"
```

```rust
use iana_spi::spi_numbers;

assert_eq!(spi_numbers::ID, "spi-numbers");
```

## Metadata

Enable `metadata` to access `spi_numbers::REGISTRIES` and the crate's `GROUPS`.
