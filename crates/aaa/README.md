# iana-aaa

Type-safe, allocation-free Rust bindings for IANA `aaa` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-aaa = "0.1.0"
```

```rust
use iana_aaa::aaa::AvpCodes;

assert_eq!(AvpCodes::RADIUS_ATTRIBUTES.as_str(), "Radius attributes");
```

## Metadata

Enable `metadata` to access `aaa::REGISTRIES` and the crate's `GROUPS`.
