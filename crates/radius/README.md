# iana-radius

Type-safe, allocation-free Rust bindings for IANA `radius` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-radius = "0.1.0"
```

```rust
use iana_radius::radius_types::ValuesForRadiusAttribute6ServiceType;

assert_eq!(ValuesForRadiusAttribute6ServiceType::LOGIN.value(), 1);
```
