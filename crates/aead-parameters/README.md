# iana-aead-parameters

Type-safe, allocation-free Rust bindings for IANA `aead-parameters` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-aead-parameters = "0.1.0"
```

```rust
use iana_aead_parameters::aead::AeadAlgorithms;

assert_eq!(AeadAlgorithms::AEAD_AES_128_GCM.value(), 1);
```

## Metadata

Enable `metadata` to access `aead::REGISTRIES` and the crate's `GROUPS`.
