# iana-pcp-parameters

Type-safe, allocation-free Rust bindings for IANA `pcp-parameters` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-pcp-parameters = "0.1.0"
```

```rust
use iana_pcp_parameters::pcp::PcpOpcodes;

assert_eq!(PcpOpcodes::ANNOUNCE.value(), 0);
```

## Metadata

Enable `metadata` to access `pcp::REGISTRIES` and the crate's `GROUPS`.
