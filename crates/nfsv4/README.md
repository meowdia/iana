# iana-nfsv4

Type-safe, allocation-free Rust bindings for IANA `nfsv4` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-nfsv4 = { version = "0.1.0", features = ["nfsv4-device-id-notifications"] }
```

```rust
use iana_nfsv4::nfsv4_device_id_notifications::Nfsv4DeviceIdNotifications;

assert_eq!(Nfsv4DeviceIdNotifications::NOTIFY_DEVICEID4_CHANGE.value(), 1);
```
