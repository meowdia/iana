# iana-phbid-codes

Type-safe, allocation-free Rust bindings for IANA `phbid-codes` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-phbid-codes = "0.1.0"
```

```rust
use iana_phbid_codes::phbid_codes;

assert_eq!(phbid_codes::ID, "phbid-codes");
```

## Metadata

Enable `metadata` to access `phbid_codes::REGISTRIES` and the crate's `GROUPS`.
