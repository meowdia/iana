# iana-snmp

Type-safe, allocation-free Rust bindings for IANA `snmp` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-snmp = "0.1.0"
```

```rust
use iana_snmp::snmp_number_spaces::SecurityModels;

assert_eq!(SecurityModels::USER_BASED_SECURITY_MODEL_USM.value(), 3);
```

## Metadata

Enable `metadata` to access `snmp_number_spaces::REGISTRIES` and the crate's `GROUPS`.
