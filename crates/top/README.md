# iana-top

Type-safe, allocation-free Rust bindings for IANA `top` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-top = "0.1.0"
```

```rust
use iana_top::top_level_media_types::TopLevelMediaTypes;

assert_eq!(TopLevelMediaTypes::APPLICATION.as_str(), "application");
```

## Metadata

Enable `metadata` to access `top_level_media_types::REGISTRIES` and the crate's `GROUPS`.
