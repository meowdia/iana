# iana-pkix

Type-safe, allocation-free Rust bindings for IANA `pkix` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-pkix = "0.1.0"
```

```rust
use iana_pkix::pkix::PkixSrvProtocolLabels;

assert_eq!(PkixSrvProtocolLabels::PKIXREP.as_str(), "_PKIXREP");
```

## Metadata

Enable `metadata` to access `pkix::REGISTRIES` and the crate's `GROUPS`.
