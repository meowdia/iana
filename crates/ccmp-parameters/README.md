# iana-ccmp-parameters

Type-safe, allocation-free Rust bindings for IANA `ccmp-parameters` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-ccmp-parameters = "0.1.0"
```

```rust
use iana_ccmp_parameters::ccmp::CcmpMessageTypes;

assert_eq!(CcmpMessageTypes::OPTIONSREQUEST.as_str(), "optionsRequest");
```

## Metadata

Enable `metadata` to access `ccmp::REGISTRIES` and the crate's `GROUPS`.
