# iana-captive

Type-safe, allocation-free Rust bindings for IANA `captive` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-captive = "0.1.0"
```

```rust
use iana_captive::captive_portals;

assert_eq!(captive_portals::ID, "captive-portals");
```

## Metadata

Enable `metadata` to access `captive_portals::REGISTRIES` and the crate's `GROUPS`.
