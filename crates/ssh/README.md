# iana-ssh

Type-safe, allocation-free Rust bindings for IANA `ssh` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-ssh = "0.1.0"
```

```rust
use iana_ssh::ssh::MessageNumbers;

assert_eq!(MessageNumbers::SSH_MSG_DISCONNECT.value(), 1);
```

## Metadata

Enable `metadata` to access `ssh::REGISTRIES` and the crate's `GROUPS`.
