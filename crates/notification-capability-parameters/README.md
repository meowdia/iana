# iana-notification-capability-parameters

Type-safe, allocation-free Rust bindings for IANA `notification-capability-parameters` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-notification-capability-parameters = "0.1.0"
```

```rust
use iana_notification_capability_parameters::notification_capability::NotificationCapabilityParameters;

assert_eq!(NotificationCapabilityParameters::ONLINE.as_str(), "online");
```
