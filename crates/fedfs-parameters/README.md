# iana-fedfs-parameters

Type-safe, allocation-free Rust bindings for IANA `fedfs-parameters` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-fedfs-parameters = "0.1.0"
```

```rust
use iana_fedfs_parameters::fedfs::FedfsObjectIdentifiers;

assert_eq!(FedfsObjectIdentifiers::V1_3_6_1_4_1_31103_1_1.as_str(), "1.3.6.1.4.1.31103.1.1");
```

## Metadata

Enable `metadata` to access `fedfs::REGISTRIES` and the crate's `GROUPS`.
