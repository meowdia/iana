# iana-reputation-parameters

Type-safe, allocation-free Rust bindings for IANA `reputation-parameters` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-reputation-parameters = "0.1.0"
```

```rust
use iana_reputation_parameters::reputation::ReputationApplications;

assert_eq!(ReputationApplications::EMAIL_ID.as_str(), "email-id");
```

## Metadata

Enable `metadata` to access `reputation::REGISTRIES` and the crate's `GROUPS`.
