# iana-mobileip-numbers

Type-safe, allocation-free Rust bindings for IANA `mobileip-numbers` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-mobileip-numbers = "0.1.0"
```

```rust
use iana_mobileip_numbers::mobileip_numbers::MobileIpMessageTypes;

assert_eq!(MobileIpMessageTypes::REGISTRATION_REQUEST.value(), 1);
```

## Metadata

Enable `metadata` to access `mobileip_numbers::REGISTRIES` and the crate's `GROUPS`.
