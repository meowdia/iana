# iana-tcp

Type-safe, allocation-free Rust bindings for IANA `tcp` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-tcp = { version = "0.1.0", features = ["tcp-parameters"] }
```

```rust
use iana_tcp::tcp::TcpOptionKindNumbers;

assert_eq!(TcpOptionKindNumbers::END_OF_OPTION_LIST.value(), 0);
```

## Features

No catalogs are enabled by default. Add `metadata` alongside catalog features
to access their `REGISTRIES` and the crate's `GROUPS`.

| Feature | Module |
|---|---|
| [`tcp-convert-protocol-parameters`](https://www.iana.org/assignments/tcp-convert-protocol-parameters/) | `tcp_convert_protocol` |
| [`tcp-header-flags`](https://www.iana.org/assignments/tcp-header-flags/) | `tcp_header_flags` |
| [`tcp-parameters`](https://www.iana.org/assignments/tcp-parameters/) | `tcp` |
