# iana-nts

Type-safe, allocation-free Rust bindings for IANA `nts` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-nts = "0.1.0"
```

```rust
use iana_nts::nts::NetworkTimeSecurityKeyEstablishmentRecordTypes;

assert_eq!(NetworkTimeSecurityKeyEstablishmentRecordTypes::END_OF_MESSAGE.value(), 0);
```

## Metadata

Enable `metadata` to access `nts::REGISTRIES` and the crate's `GROUPS`.
