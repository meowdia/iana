# iana-mdn

Type-safe, allocation-free Rust bindings for IANA `mdn` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-mdn = "0.1.0"
```

```rust
use iana_mdn::mdn::MdnDispositionModifierNames;

assert_eq!(MdnDispositionModifierNames::ALTERNATIVE_PREFERRED.as_str(), "Alternative-preferred");
```

## Metadata

Enable `metadata` to access `mdn::REGISTRIES` and the crate's `GROUPS`.
