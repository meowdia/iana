# iana-version

Type-safe, allocation-free Rust bindings for IANA `version` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-version = { version = "0.1.0", features = ["version-numbers"] }
```

```rust
use iana_version::version_numbers::IpVersionNumbers;

assert_eq!(IpVersionNumbers::V4.value(), 4);
```

## Features

No catalogs are enabled by default. Add `metadata` alongside catalog features
to access their `REGISTRIES` and the crate's `GROUPS`.

| Feature | Module |
|---|---|
| [`version-numbers`](https://www.iana.org/assignments/version-numbers/) | `version_numbers` |
| [`version-symbols`](https://www.iana.org/assignments/version-symbols/) | `version_symbols` |
