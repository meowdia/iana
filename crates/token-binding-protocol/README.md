# iana-token-binding-protocol

Type-safe, allocation-free Rust bindings for IANA `token-binding-protocol` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-token-binding-protocol = "0.1.0"
```

```rust
use iana_token_binding_protocol::token_binding_protocol::TokenBindingKeyParameters;

assert_eq!(TokenBindingKeyParameters::RSA2048_PKCS1_5.value(), 0);
```

## Metadata

Enable `metadata` to access `token_binding_protocol::REGISTRIES` and the crate's `GROUPS`.
