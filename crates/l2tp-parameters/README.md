# iana-l2tp-parameters

Type-safe, allocation-free Rust bindings for IANA `l2tp-parameters` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-l2tp-parameters = "0.1.0"
```

```rust
use iana_l2tp_parameters::l2tp::ControlMessageAttributeValuePairs;

assert_eq!(ControlMessageAttributeValuePairs::MESSAGE_TYPE_AVP_ALSO_SEE_MESSAGE_TYPE_AVP_VALUES_BELOW.value(), 0);
```

## Metadata

Enable `metadata` to access `l2tp::REGISTRIES` and the crate's `GROUPS`.
