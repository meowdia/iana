# iana-sframe

Type-safe, allocation-free Rust bindings for IANA `sframe` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-sframe = "0.1.0"
```

```rust
use iana_sframe::sframe::SframeCipherSuites;

assert_eq!(SframeCipherSuites::AES_128_CTR_HMAC_SHA256_80.value(), 1);
```

## Metadata

Enable `metadata` to access `sframe::REGISTRIES` and the crate's `GROUPS`.
