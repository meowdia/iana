# iana-xcap

Type-safe, allocation-free Rust bindings for IANA `xcap` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-xcap = "0.1.0"
```

```rust
use iana_xcap::xcap;

assert_eq!(xcap::ID, "xcap-parameters");
```

## Metadata

Enable `metadata` to access `xcap::REGISTRIES` and the crate's `GROUPS`.
