# iana-auto

Type-safe, allocation-free Rust bindings for IANA `auto` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-auto = { version = "0.1.0", features = ["auto-response-parameters"] }
```

```rust
use iana_auto::auto_response;

assert_eq!(auto_response::ID, "auto-response-parameters");
```

## Features

No catalogs are enabled by default. Add `metadata` alongside catalog features
to access their `REGISTRIES` and the crate's `GROUPS`.

| Feature | Module |
|---|---|
| [`auto-response-parameters`](https://www.iana.org/assignments/auto-response-parameters/) | `auto_response` |
| [`auto-submitted-keywords`](https://www.iana.org/assignments/auto-submitted-keywords/) | `auto_submitted_keywords` |
