# iana-ftp

Type-safe, allocation-free Rust bindings for IANA `ftp` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-ftp = "0.1.0"
```

```rust
use iana_ftp::ftp_commands_extensions;

assert_eq!(ftp_commands_extensions::ID, "ftp-commands-extensions");
```

## Metadata

Enable `metadata` to access `ftp_commands_extensions::REGISTRIES` and the crate's `GROUPS`.
