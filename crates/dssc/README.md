# iana-dssc

Type-safe, allocation-free Rust bindings for IANA `dssc` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-dssc = "0.1.0"
```

```rust
use iana_dssc::dssc::ParameterDefinitions;

assert_eq!(ParameterDefinitions::MODULUSLENGTH.as_str(), "moduluslength");
```

## Metadata

Enable `metadata` to access `dssc::REGISTRIES` and the crate's `GROUPS`.
