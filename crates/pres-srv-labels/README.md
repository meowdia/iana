# iana-pres-srv-labels

Type-safe, allocation-free Rust bindings for IANA `pres-srv-labels` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-pres-srv-labels = "0.1.0"
```

```rust
use iana_pres_srv_labels::pres_srv_labels::PresenceSrvProtocolLabels;

assert_eq!(PresenceSrvProtocolLabels::SIP.as_str(), "_sip");
```
