# iana-mta

Type-safe, allocation-free Rust bindings for IANA `mta` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-mta = "0.1.0"
```

```rust
use iana_mta::mta_sts::MtaStsTxtRecordFields;

assert_eq!(MtaStsTxtRecordFields::V.as_str(), "v");
```

## Metadata

Enable `metadata` to access `mta_sts::REGISTRIES` and the crate's `GROUPS`.
