# iana-privacy

Type-safe, allocation-free Rust bindings for IANA `privacy` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-privacy = "0.1.0"
```

```rust
use iana_privacy::privacy_pass::PrivacyPassTokenTypes;

assert_eq!(PrivacyPassTokenTypes::VOPRF_P_384_SHA_384.value(), 1);
```

## Metadata

Enable `metadata` to access `privacy_pass::REGISTRIES` and the crate's `GROUPS`.
