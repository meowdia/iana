# iana-ldap

Type-safe, allocation-free Rust bindings for IANA `ldap` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-ldap = "0.1.0"
```

```rust
use iana_ldap::ldap::InternetDirectoryNumbersIsoOrgDodInternetDirectory13611;

assert_eq!(InternetDirectoryNumbersIsoOrgDodInternetDirectory13611::NETWORK_INFO_SERVICE_SCHEMA.value(), 1);
```

## Metadata

Enable `metadata` to access `ldap::REGISTRIES` and the crate's `GROUPS`.
