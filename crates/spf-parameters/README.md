# iana-spf-parameters

Type-safe, allocation-free Rust bindings for IANA `spf-parameters` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-spf-parameters = "0.1.0"
```

```rust
use iana_spf_parameters::spf::ModifierNames;

assert_eq!(ModifierNames::EXP.as_str(), "exp");
```

## Metadata

Enable `metadata` to access `spf::REGISTRIES` and the crate's `GROUPS`.
