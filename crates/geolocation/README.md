# iana-geolocation

Type-safe, allocation-free Rust bindings for IANA `geolocation` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-geolocation = "0.1.0"
```

```rust
use iana_geolocation::geolocation_policy::GeolocationPolicyLocationProfileNames;

assert_eq!(GeolocationPolicyLocationProfileNames::GEODETIC_CONDITION.as_str(), "geodetic-condition");
```

## Metadata

Enable `metadata` to access `geolocation_policy::REGISTRIES` and the crate's `GROUPS`.
