# iana-msdp

Type-safe, allocation-free Rust bindings for IANA `msdp` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-msdp = "0.1.0"
```

```rust
use iana_msdp::msdp_tlv_values::MsdpTlvValues;

assert_eq!(MsdpTlvValues::IPV4_SOURCE_ACTIVE.value(), 1);
```

## Metadata

Enable `metadata` to access `msdp_tlv_values::REGISTRIES` and the crate's `GROUPS`.
