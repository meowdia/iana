# iana-tel-uri-parameters

Type-safe, allocation-free Rust bindings for IANA `tel-uri-parameters` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-tel-uri-parameters = "0.1.0"
```

```rust
use iana_tel_uri_parameters::tel_uri;

assert_eq!(tel_uri::ID, "tel-uri-parameters");
```
