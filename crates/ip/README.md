# iana-ip

Type-safe, allocation-free Rust bindings for IANA `ip` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-ip = { version = "0.1.0", features = ["ip-parameters"] }
```

```rust
use iana_ip::ip::IpOptionNumbers;

assert_eq!(IpOptionNumbers::EOOL_END_OF_OPTIONS_LIST.value(), 0);
```

## Features

No catalogs are enabled by default. Add `metadata` alongside catalog features
to access their `REGISTRIES` and the crate's `GROUPS`.

| Feature | Module |
|---|---|
| [`ip-over-IEEE1394`](https://www.iana.org/assignments/ip-over-IEEE1394/) | `ip_over_ieee1394` |
| [`ip-parameters`](https://www.iana.org/assignments/ip-parameters/) | `ip` |
| [`ip-xns-mapping`](https://www.iana.org/assignments/ip-xns-mapping/) | `ip_xns_mapping` |
