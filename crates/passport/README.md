# iana-passport

Type-safe, allocation-free Rust bindings for IANA `passport` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-passport = "0.1.0"
```

```rust
use iana_passport::passport::PersonalAssertionTokenPassportExtensions;

assert_eq!(PersonalAssertionTokenPassportExtensions::RPH.as_str(), "rph");
```

## Metadata

Enable `metadata` to access `passport::REGISTRIES` and the crate's `GROUPS`.
