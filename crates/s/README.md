# iana-s

Type-safe, allocation-free Rust bindings for IANA `s` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-s = { version = "0.1.0", features = ["s-naptr-parameters"] }
```

```rust
use iana_s::s_naptr;

assert_eq!(s_naptr::ID, "s-naptr-parameters");
```

## Features

No catalogs are enabled by default. Add `metadata` alongside catalog features
to access their `REGISTRIES` and the crate's `GROUPS`.

| Feature | Module |
|---|---|
| [`s-naptr-parameters`](https://www.iana.org/assignments/s-naptr-parameters/) | `s_naptr` |
| [`s-pmsi-parameters`](https://www.iana.org/assignments/s-pmsi-parameters/) | `s_pmsi` |
