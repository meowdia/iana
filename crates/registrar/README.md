# iana-registrar

Type-safe, allocation-free Rust bindings for IANA `registrar` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-registrar = "0.1.0"
```

```rust
use iana_registrar::registrar_ids::RegistrarIds;

assert_eq!(RegistrarIds::NETWORK_SOLUTIONS_LLC.value(), 2);
```

## Metadata

Enable `metadata` to access `registrar_ids::REGISTRIES` and the crate's `GROUPS`.
