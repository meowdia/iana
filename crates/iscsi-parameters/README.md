# iana-iscsi-parameters

Type-safe, allocation-free Rust bindings for IANA `iscsi-parameters` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-iscsi-parameters = "0.1.0"
```

```rust
use iana_iscsi_parameters::iscsi::IscsiAuthenticationMethods;

assert_eq!(IscsiAuthenticationMethods::CHAP.value(), 1);
```

## Metadata

Enable `metadata` to access `iscsi::REGISTRIES` and the crate's `GROUPS`.
