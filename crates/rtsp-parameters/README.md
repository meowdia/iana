# iana-rtsp-parameters

Type-safe, allocation-free Rust bindings for IANA `rtsp-parameters` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-rtsp-parameters = "0.1.0"
```

```rust
use iana_rtsp_parameters::rtsp::Rtsp10Methods;

assert_eq!(Rtsp10Methods::DESCRIBE.as_str(), "DESCRIBE");
```

## Metadata

Enable `metadata` to access `rtsp::REGISTRIES` and the crate's `GROUPS`.
