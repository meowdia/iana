# iana-olsr

Type-safe, allocation-free Rust bindings for IANA `olsr` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-olsr = "0.1.0"
```

```rust
use iana_olsr::olsr_types::OlsrProtocolMessageTypes;

assert_eq!(OlsrProtocolMessageTypes::HELLO_MESSAGE.value(), 1);
```

## Metadata

Enable `metadata` to access `olsr_types::REGISTRIES` and the crate's `GROUPS`.
