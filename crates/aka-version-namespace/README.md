# iana-aka-version-namespace

Type-safe, allocation-free Rust bindings for IANA `aka-version-namespace` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-aka-version-namespace = "0.1.0"
```

```rust
use iana_aka_version_namespace::aka_version_namespace;

assert_eq!(aka_version_namespace::ID, "aka-version-namespace");
```
