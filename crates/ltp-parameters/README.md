# iana-ltp-parameters

Type-safe, allocation-free Rust bindings for IANA `ltp-parameters` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-ltp-parameters = "0.1.0"
```

```rust
use iana_ltp_parameters::ltp::LtpExtensionTags;

assert_eq!(LtpExtensionTags::LTP_AUTHENTICATION_EXTENSION.value(), 0);
```

## Metadata

Enable `metadata` to access `ltp::REGISTRIES` and the crate's `GROUPS`.
