# iana-alert-urns

Type-safe, allocation-free Rust bindings for IANA `alert-urns` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-alert-urns = "0.1.0"
```

```rust
use iana_alert_urns::alert_urns::AlertUrnIdentifiers;

assert_eq!(AlertUrnIdentifiers::SERVICE.as_str(), "service");
```
