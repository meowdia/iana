# iana-trill

Type-safe, allocation-free Rust bindings for IANA `trill` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-trill = "0.1.0"
```

```rust
use iana_trill::trill::TrillNicknames;

assert_eq!(TrillNicknames::V0X0000.value(), 0);
```

## Metadata

Enable `metadata` to access `trill::REGISTRIES` and the crate's `GROUPS`.
