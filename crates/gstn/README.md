# iana-gstn

Type-safe, allocation-free Rust bindings for IANA `gstn` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-gstn = "0.1.0"
```

```rust
use iana_gstn::gstn_extensions;

assert_eq!(gstn_extensions::ID, "gstn-extensions");
```

## Metadata

Enable `metadata` to access `gstn_extensions::REGISTRIES` and the crate's `GROUPS`.
