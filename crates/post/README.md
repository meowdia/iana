# iana-post

Type-safe, allocation-free Rust bindings for IANA `post` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-post = "0.1.0"
```

```rust
use iana_post::post_stack_first_nibble::PostStackFirstNibble;

assert_eq!(PostStackFirstNibble::DETNET_CONTROL_WORD.value(), 0);
```
