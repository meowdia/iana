# iana-madcap

Type-safe, allocation-free Rust bindings for IANA `madcap` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-madcap = "0.1.0"
```

```rust
use iana_madcap::madcap::MadcapMessageTypes;

assert_eq!(MadcapMessageTypes::DISCOVER.value(), 1);
```

## Metadata

Enable `metadata` to access `madcap::REGISTRIES` and the crate's `GROUPS`.
