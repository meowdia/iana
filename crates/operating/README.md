# iana-operating

Type-safe, allocation-free Rust bindings for IANA `operating` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-operating = "0.1.0"
```

```rust
use iana_operating::operating_system_names::OperatingSystemNames;

assert_eq!(OperatingSystemNames::AEGIS.as_str(), "AEGIS");
```

## Metadata

Enable `metadata` to access `operating_system_names::REGISTRIES` and the crate's `GROUPS`.
