# iana-rift

Type-safe, allocation-free Rust bindings for IANA `rift` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-rift = "0.1.0"
```

```rust
use iana_rift::rift::RiftSecurityAlgorithms;

assert_eq!(RiftSecurityAlgorithms::HMAC_SHA256.as_str(), "HMAC-SHA256");
```

## Metadata

Enable `metadata` to access `rift::REGISTRIES` and the crate's `GROUPS`.
