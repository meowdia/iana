# iana-stringprep-profiles

Type-safe, allocation-free Rust bindings for IANA `stringprep-profiles` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-stringprep-profiles = "0.1.0"
```

```rust
use iana_stringprep_profiles::stringprep_profiles::StringprepProfiles;

assert_eq!(StringprepProfiles::ISCSI.as_str(), "iSCSI");
```

## Metadata

Enable `metadata` to access `stringprep_profiles::REGISTRIES` and the crate's `GROUPS`.
