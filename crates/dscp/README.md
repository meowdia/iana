# iana-dscp

Type-safe, allocation-free Rust bindings for IANA `dscp` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-dscp = "0.1.0"
```

```rust
use iana_dscp::dscp_registry::DscpPool1Codepoints;

assert_eq!(DscpPool1Codepoints::CS0.as_str(), "CS0");
```

## Metadata

Enable `metadata` to access `dscp_registry::REGISTRIES` and the crate's `GROUPS`.
