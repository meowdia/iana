# iana-jmap

Type-safe, allocation-free Rust bindings for IANA `jmap` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-jmap = "0.1.0"
```

```rust
use iana_jmap::jmap::JmapCapabilities;

assert_eq!(JmapCapabilities::URN_IETF_PARAMS_JMAP_CORE.as_str(), "urn:ietf:params:jmap:core");
```

## Metadata

Enable `metadata` to access `jmap::REGISTRIES` and the crate's `GROUPS`.
