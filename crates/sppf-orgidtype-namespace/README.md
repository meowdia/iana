# iana-sppf-orgidtype-namespace

Type-safe, allocation-free Rust bindings for IANA `sppf-orgidtype-namespace` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-sppf-orgidtype-namespace = "0.1.0"
```

```rust
use iana_sppf_orgidtype_namespace::sppf_orgidtype_namespace::SppfOrgidtypeNamespaces;

assert_eq!(SppfOrgidtypeNamespaces::IANA_ENTERPRISE_NUMBERS.as_str(), "IANA Enterprise Numbers");
```

## Metadata

Enable `metadata` to access `sppf_orgidtype_namespace::REGISTRIES` and the crate's `GROUPS`.
