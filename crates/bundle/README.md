# iana-bundle

Type-safe, allocation-free Rust bindings for IANA `bundle` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-bundle = "0.1.0"
```

```rust
use iana_bundle::bundle::BundleBlockTypes;

assert_eq!(BundleBlockTypes::BUNDLE_PAYLOAD_BLOCK.value(), 1);
```

## Metadata

Enable `metadata` to access `bundle::REGISTRIES` and the crate's `GROUPS`.
