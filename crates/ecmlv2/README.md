# iana-ecmlv2

Type-safe, allocation-free Rust bindings for IANA `ecmlv2` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-ecmlv2 = "0.1.0"
```

```rust
use iana_ecmlv2::ecmlv2::EcomPaymentCardProtocolRegistry;

assert_eq!(EcomPaymentCardProtocolRegistry::NONE.as_str(), "none");
```

## Metadata

Enable `metadata` to access `ecmlv2::REGISTRIES` and the crate's `GROUPS`.
