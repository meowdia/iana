# iana-scim

Type-safe, allocation-free Rust bindings for IANA `scim` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-scim = "0.1.0"
```

```rust
use iana_scim::scim::ScimSchemaUrisForDataResources;

assert_eq!(ScimSchemaUrisForDataResources::URN_IETF_PARAMS_SCIM_SCHEMAS_CORE_2_0_USER.as_str(), "urn:ietf:params:scim:schemas:core:2.0:User");
```

## Metadata

Enable `metadata` to access `scim::REGISTRIES` and the crate's `GROUPS`.
