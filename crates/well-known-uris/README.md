# iana-well-known-uris

Type-safe, allocation-free Rust bindings for IANA `well-known-uris` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-well-known-uris = "0.1.0"
```

```rust
use iana_well_known_uris::well_known_uris::WellKnownUris;

assert_eq!(WellKnownUris::ACME_CHALLENGE.as_str(), "acme-challenge");
```

## Metadata

Enable `metadata` to access `well_known_uris::REGISTRIES` and the crate's `GROUPS`.
