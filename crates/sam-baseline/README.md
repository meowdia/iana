# iana-sam-baseline

Type-safe, allocation-free Rust bindings for IANA `sam-baseline` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-sam-baseline = "0.1.0"
```

```rust
use iana_sam_baseline::sam_baseline::SamAlmAlgorithmIds;

assert_eq!(SamAlmAlgorithmIds::INVALID_ALG.value(), 0);
```
