# iana-service

Type-safe, allocation-free Rust bindings for IANA `service` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-service = { version = "0.2.0", features = ["service-codes"] }
```

```rust
use iana_service::service_codes::ServiceCodes;

assert_eq!(ServiceCodes::LTP.value(), 7107696);
```

## Features

No catalogs are enabled by default. Add `metadata` alongside catalog features
to access their `REGISTRIES` and the crate's `GROUPS`.
