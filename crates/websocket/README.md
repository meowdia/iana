# iana-websocket

Type-safe, allocation-free Rust bindings for IANA `websocket` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-websocket = "0.1.0"
```

```rust
use iana_websocket::websocket::WebsocketVersionNumberRegistry;

assert_eq!(WebsocketVersionNumberRegistry::V0.value(), 0);
```

## Metadata

Enable `metadata` to access `websocket::REGISTRIES` and the crate's `GROUPS`.
