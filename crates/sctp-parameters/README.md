# iana-sctp-parameters

Type-safe, allocation-free Rust bindings for IANA `sctp-parameters` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-sctp-parameters = "0.1.0"
```

```rust
use iana_sctp_parameters::sctp::ChunkTypes;

assert_eq!(ChunkTypes::PAYLOAD_DATA_DATA.value(), 0);
```

## Metadata

Enable `metadata` to access `sctp::REGISTRIES` and the crate's `GROUPS`.
