# iana-osi-nsapa-numbers

Type-safe, allocation-free Rust bindings for IANA `osi-nsapa-numbers` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-osi-nsapa-numbers = "0.1.0"
```

```rust
use iana_osi_nsapa_numbers::osi_nsapa_numbers::OsiNsapaInternetCodePointsForAfi35;

assert_eq!(OsiNsapaInternetCodePointsForAfi35::EMBEDDED_IPV6_ADDRESS.value(), 0);
```
