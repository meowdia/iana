# iana-method

Type-safe, allocation-free Rust bindings for IANA `method` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-method = "0.1.0"
```

```rust
use iana_method::method_tokens::MethodTokens;

assert_eq!(MethodTokens::A_GNSS.as_str(), "A-GNSS");
```

## Metadata

Enable `metadata` to access `method_tokens::REGISTRIES` and the crate's `GROUPS`.
