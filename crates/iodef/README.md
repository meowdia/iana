# iana-iodef

Type-safe, allocation-free Rust bindings for IANA `iodef` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-iodef = "0.1.0"
```

```rust
use iana_iodef::iodef::StructuredCybersecurityInformationSciSpecifications;

assert_eq!(StructuredCybersecurityInformationSciSpecifications::MALWARE_METADATA_EXCHANGE_FORMAT.as_str(), "Malware Metadata Exchange Format");
```

## Metadata

Enable `metadata` to access `iodef::REGISTRIES` and the crate's `GROUPS`.
