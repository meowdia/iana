# iana-acme

Type-safe, allocation-free Rust bindings for IANA `acme` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-acme = "0.1.0"
```

```rust
use iana_acme::acme::AcmeAccountObjectFields;

assert_eq!(AcmeAccountObjectFields::STATUS.as_str(), "status");
```

## Metadata

Enable `metadata` to access `acme::REGISTRIES` and the crate's `GROUPS`.
