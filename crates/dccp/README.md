# iana-dccp

Type-safe, allocation-free Rust bindings for IANA `dccp` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-dccp = { version = "0.1.0", features = ["dccp-parameters"] }
```

```rust
use iana_dccp::dccp::PacketTypes;

assert_eq!(PacketTypes::DCCP_REQUEST.value(), 0);
```

## Features

No catalogs are enabled by default. Add `metadata` alongside catalog features
to access their `REGISTRIES` and the crate's `GROUPS`.

| Feature | Module |
|---|---|
| [`dccp-ccid2-parameters`](https://www.iana.org/assignments/dccp-ccid2-parameters/) | `dccp_ccid2` |
| [`dccp-ccid3-parameters`](https://www.iana.org/assignments/dccp-ccid3-parameters/) | `dccp_ccid3` |
| [`dccp-ccid4-parameters`](https://www.iana.org/assignments/dccp-ccid4-parameters/) | `dccp_ccid4` |
| [`dccp-parameters`](https://www.iana.org/assignments/dccp-parameters/) | `dccp` |
