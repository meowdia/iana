# iana-gsmpv3

Type-safe, allocation-free Rust bindings for IANA `gsmpv3` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-gsmpv3 = { version = "0.1.0", features = ["gsmpv3-adapt"] }
```

```rust
use iana_gsmpv3::gsmpv3_adapt::AdaptationTypes;

assert_eq!(AdaptationTypes::PPP.value(), 256);
```
