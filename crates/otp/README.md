# iana-otp

Type-safe, allocation-free Rust bindings for IANA `otp` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-otp = "0.1.0"
```

```rust
use iana_otp::otp::AlgorithmIdentifier;

assert_eq!(AlgorithmIdentifier::MD4.as_str(), "md4");
```

## Metadata

Enable `metadata` to access `otp::REGISTRIES` and the crate's `GROUPS`.
