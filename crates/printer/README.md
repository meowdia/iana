# iana-printer

Type-safe, allocation-free Rust bindings for IANA `printer` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-printer = "0.1.0"
```

```rust
use iana_printer::printer_language_numbers;

assert_eq!(printer_language_numbers::ID, "printer-language-numbers");
```

## Metadata

Enable `metadata` to access `printer_language_numbers::REGISTRIES` and the crate's `GROUPS`.
