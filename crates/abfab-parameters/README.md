# iana-abfab-parameters

Type-safe, allocation-free Rust bindings for IANA `abfab-parameters` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-abfab-parameters = "0.1.0"
```

```rust
use iana_abfab_parameters::abfab::AbfabUrnParameters;

assert_eq!(AbfabUrnParameters::BINDINGS_RADIUS.as_str(), "bindings:radius");
```

## Metadata

Enable `metadata` to access `abfab::REGISTRIES` and the crate's `GROUPS`.
