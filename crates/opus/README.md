# iana-opus

Type-safe, allocation-free Rust bindings for IANA `opus` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-opus = "0.1.0"
```

```rust
use iana_opus::opus_channel_mapping_families::OpusChannelMappingFamilies;

assert_eq!(OpusChannelMappingFamilies::MONO_L_R_STEREO.value(), 0);
```

## Metadata

Enable `metadata` to access `opus_channel_mapping_families::REGISTRIES` and the crate's `GROUPS`.
