# iana-teep

Type-safe, allocation-free Rust bindings for IANA `teep` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-teep = "0.1.0"
```

```rust
use iana_teep::teep::TeepMessageTypes;

assert_eq!(TeepMessageTypes::TEEP_TYPE_QUERY_REQUEST.value(), 1);
```

## Metadata

Enable `metadata` to access `teep::REGISTRIES` and the crate's `GROUPS`.
