# iana-sgmp

Type-safe, allocation-free Rust bindings for IANA `sgmp` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-sgmp = "0.1.0"
```

```rust
use iana_sgmp::sgmp_vendor_specific_codes::SgmpVendorSpecificCodesObsolete;

assert_eq!(SgmpVendorSpecificCodesObsolete::PROTEON.as_str(), "Proteon");
```

## Metadata

Enable `metadata` to access `sgmp_vendor_specific_codes::REGISTRIES` and the crate's `GROUPS`.
