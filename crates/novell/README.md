# iana-novell

Type-safe, allocation-free Rust bindings for IANA `novell` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-novell = "0.1.0"
```

```rust
use iana_novell::novell_sap_numbers;

assert_eq!(novell_sap_numbers::ID, "novell-sap-numbers");
```
