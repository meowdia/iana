# iana-rtfm

Type-safe, allocation-free Rust bindings for IANA `rtfm` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-rtfm = "0.1.0"
```

```rust
use iana_rtfm::rtfm::PatternMatchingEnginePmeOpcodes;

assert_eq!(PatternMatchingEnginePmeOpcodes::V1.value(), 1);
```

## Metadata

Enable `metadata` to access `rtfm::REGISTRIES` and the crate's `GROUPS`.
