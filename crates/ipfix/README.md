# iana-ipfix

Type-safe, allocation-free Rust bindings for IANA `ipfix` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-ipfix = "0.1.0"
```

```rust
use iana_ipfix::ipfix::IpfixMplsLabelTypeValue46;

assert_eq!(IpfixMplsLabelTypeValue46::UNKNOWN_THE_MPLS_LABEL_TYPE_IS_NOT_KNOWN.value(), 0);
```

## Metadata

Enable `metadata` to access `ipfix::REGISTRIES` and the crate's `GROUPS`.
