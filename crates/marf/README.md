# iana-marf

Type-safe, allocation-free Rust bindings for IANA `marf` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-marf = "0.1.0"
```

```rust
use iana_marf::marf::FeedbackReportHeaderFields;

assert_eq!(FeedbackReportHeaderFields::ARRIVAL_DATE.as_str(), "Arrival-Date");
```

## Metadata

Enable `metadata` to access `marf::REGISTRIES` and the crate's `GROUPS`.
