# iana-igp

Type-safe, allocation-free Rust bindings for IANA `igp` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-igp = "0.1.0"
```

```rust
use iana_igp::igp::IgpAlgorithmTypes;

assert_eq!(IgpAlgorithmTypes::SHORTEST_PATH_FIRST_SPF_ALGORITHM_BASED_ON_LINK_METRIC_THIS_IS_THE_STANDARD_SHORTEST_PATH_ALGORITHM_AS_COMPUTED_BY_THE_IGP_PROTOCOL_CONSISTENT_WITH_THE_DEPLOYED_PRACTICE_FOR_LINK_STATE_PROTOCOLS_ALGORITHM_0_PERMITS_ANY_NODE_TO_OVERWRITE_THE_SPF_PATH_WITH_A_DIFFERENT_PATH_BASED_ON_ITS_LOCAL_POLICY.value(), 0);
```
