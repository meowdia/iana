# iana-stamp-tlv-types

Type-safe, allocation-free Rust bindings for IANA `stamp-tlv-types` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-stamp-tlv-types = "0.1.0"
```

```rust
use iana_stamp_tlv_types::stamp_tlv_types::StampTlvTypes;

assert_eq!(StampTlvTypes::EXTRA_PADDING.value(), 1);
```
