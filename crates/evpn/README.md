# iana-evpn

Type-safe, allocation-free Rust bindings for IANA `evpn` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-evpn = "0.1.0"
```

```rust
use iana_evpn::evpn::EvpnRouteTypes;

assert_eq!(EvpnRouteTypes::ETHERNET_AUTO_DISCOVERY.value(), 1);
```

## Metadata

Enable `metadata` to access `evpn::REGISTRIES` and the crate's `GROUPS`.
