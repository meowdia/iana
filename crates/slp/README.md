# iana-slp

Type-safe, allocation-free Rust bindings for IANA `slp` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-slp = "0.1.0"
```

```rust
use iana_slp::slp_da_service::SlpRemoteServiceDiscovery;

assert_eq!(SlpRemoteServiceDiscovery::SLPDA.as_str(), "slpda");
```

## Metadata

Enable `metadata` to access `slp_da_service::REGISTRIES` and the crate's `GROUPS`.
