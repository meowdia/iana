# iana-acap

Type-safe, allocation-free Rust bindings for IANA `acap` registries.
Supports `no_std`.

## Usage

```toml
[dependencies]
iana-acap = "0.1.0"
```

```rust
use iana_acap::acap_registrations::AcapCapabilities;

assert_eq!(AcapCapabilities::STARTTLS.as_str(), "STARTTLS");
```

## Metadata

Enable `metadata` to access `acap_registrations::REGISTRIES` and the crate's `GROUPS`.
